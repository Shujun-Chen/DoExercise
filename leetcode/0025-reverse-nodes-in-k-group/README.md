# 25. Reverse Nodes in k-Group

**难度：** Hard

## 题目描述
给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，返回修改后的链表。

`k` 是一个正整数，小于等于链表长度。如果节点总数不是 `k` 的整数倍，则最后剩余的节点保持原有顺序。

你不能改变节点中的值，只能改变节点本身。

**示例 1：**
```
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]
```

**示例 2：**
```
输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

**进阶：** 你能设计一个 O(1) 额外空间的解法吗？

## 解题思路
本题是链表翻转的进阶版本，核心思路是分组处理：

1. **虚拟头节点（dummy）**：创建一个 dummy 节点指向 head，简化边界处理。使用 `prevGroup` 指针跟踪当前待翻转组的前一个节点。

2. **分组检查**：从 `prevGroup.next` 开始，遍历 k 个节点。如果不足 k 个，则直接返回结果。

3. **组内翻转**：
   - 记录当前组的起始节点 `groupStart` 和下一组的起始节点 `nextGroup`
   - 采用迭代法翻转当前组的 k 个节点，使翻转后的尾节点指向 `nextGroup`
   - 翻转完成后，将 `prevGroup.next` 指向翻转后的头节点（即原组的尾节点 `end`）

4. **更新指针**：将 `prevGroup` 移动到当前组的起始节点（即翻转后的尾节点），继续处理下一组。

关键技巧：翻转链表时，逐个将当前节点拔出并插入到 `prevGroup` 之后，同时保持翻转后的最后一个节点指向 `nextGroup`。

## 复杂度分析
- **时间复杂度：** O(n)，其中 n 是链表长度。每个节点恰好被遍历一次（分组检查 + 翻转）。
- **空间复杂度：** O(1)，只使用了若干指针变量，满足进阶要求。

## Python 解法要点
- 使用 `dummy` 节点简化头节点处理
- 内层 while 循环反转当前组：每次将 `curr` 拔出并插入到 `prevGroup.next` 位置
- 注意 `prev` 的初始值设为 `nextGroup`（翻转后的尾节点指向下一组的第一个节点）
- `curr` 遍历完整个组后（`curr == nextGroup`），退出循环

## Java 解法要点
- 与 Python 解法思路完全一致
- 注意 Java 使用 `ListNode` 类定义链表节点
- `main` 方法中使用 `assert` 进行测试，需使用 `-ea` 参数启用断言
- 注意 Java 的引用类型，指针操作与 Python 的对象引用本质相同
