# 151. Reverse Words in a String

**难度：** Medium

## 题目描述

给定一个字符串 `s`，反转字符串中单词的顺序。

单词是由非空格字符组成的序列。`s` 中的单词至少由一个空格分隔。

返回单词顺序颠倒且用单个空格连接的字符串。

注意：
- `s` 可能包含前导或尾随空格，或者多个连续空格
- 返回的字符串中，单词间应只包含一个空格，不应包含多余空格

**示例 1：**
```
输入：s = "the sky is blue"
输出："blue is sky the"
```

**示例 2：**
```
输入：s = "  hello world  "
输出："world hello"
解释：反转后的字符串不应包含前导或尾随空格。
```

**示例 3：**
```
输入：s = "a good   example"
输出："example good a"
解释：需要将单词间的多个空格缩减为单个空格。
```

**约束条件：**
- 1 &lt;= s.length &lt;= 10^4
- `s` 包含英文字母（大小写）、数字和空格 `' '`
- `s` 中至少有一个单词

**进阶：** 如果字符串在你使用的语言中是可变的，你能用 O(1) 额外空间就地解决吗？

## 解题思路

### 方法一：Python 简洁法（split + join）

利用 Python 字符串内置的 `split()` 方法：
1. `split()` 默认按任意空白字符分割，自动处理连续空格和首尾空格，不会返回空字符串
2. 用 `reversed()` 反转单词列表
3. 用 `' '.join()` 用单个空格连接

### 方法二：Java 就地反转法（满足进阶要求）

三步走策略，在字符数组上就地操作：

1. **反转整个字符串** — 将字符串完全反转，单词顺序也随之颠倒
2. **反转每个单词** — 遍历字符数组，对每个单词区间再次反转，恢复单词的正确顺序
3. **清理多余空格** — 使用双指针，去除前导/尾随空格，将连续多个空格压缩为一个

这种方法不需要额外的数组或列表，只使用字符数组本身的空间。

## 复杂度分析

**Python 解法：**
- **时间复杂度：** O(n)，`split()` 和 `join()` 都只需线性扫描
- **空间复杂度：** O(n)，需要存储分割后的单词列表

**Java 解法（就地）：**
- **时间复杂度：** O(n)，每个字符被访问常数次
- **空间复杂度：** O(1)，使用字符数组（Java 字符串不可变是语言特性，但 char[] 是就地操作）

## Python 解法要点

- `s.split()` 不加参数时，按任意空白字符分割，自动去除前导/尾随空格和连续空格
- 不要用 `s.split(' ')`，它不会处理连续空格和首尾空格
- 一行即可完成：`return ' '.join(reversed(s.split()))`
- 也可以用 `return ' '.join(s.split()[::-1])`

## Java 解法要点

- Java 字符串是不可变的，需要先转为 `char[]` 才能就地操作
- 反转单词的关键是找到每个单词的起止位置（通过空格分隔）
- 清理空格时使用双指针技巧：一个指针读取、一个指针写入
- 处理好边界条件：空字符串、只有空格的字符串、单个单词
