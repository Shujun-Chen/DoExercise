# 354. Russian Doll Envelopes

**难度：** Hard

**标签：** Array, Binary Search, Dynamic Programming, Sorting

## 题目描述

给定一个二维整数数组 `envelopes`，其中 `envelopes[i] = [w_i, h_i]` 表示第 i 个信封的宽度和高度。

当一个信封的宽度和高度**都严格大于**另一个信封的宽度和高度时，这个信封就可以套进另一个信封里（俄罗斯套娃）。

请返回最多可以套多少个信封。**注意：** 不能旋转信封。

## 解题思路

### 核心思想：转化为最长递增子序列（LIS）

俄罗斯套娃的核心条件是：对于前后两个信封 A 和 B，如果 `A.w < B.w` 且 `A.h < B.h`，则 A 可以放入 B。

这等价于在二维中找最长的递增序列。关键是排序技巧：

### 步骤

1. **排序**：按宽度升序排列。当宽度相同时，按高度**降序**排列。
   - 为什么要高度降序？因为同宽度的信封不能互相嵌套。如果按高度升序排列，LIS 算法会误认为同宽度、不同高度的信封可以嵌套。高度降序保证了同宽度的信封在 LIS 中最多只能选一个。

2. **LIS**：提取排序后的高度数组，求最长递增子序列。
   - 使用**耐心排序（Patience Sorting）+ 二分查找**优化到 O(n log n)。
   - 维护一个 `tails` 数组，`tails[i]` 表示长度为 `i+1` 的递增子序列的最小末尾值。
   - 遍历每个高度 h，在 tails 中二分查找第一个 ≥ h 的位置：
     - 如果 h 比所有 tail 都大，扩展 tails
     - 否则用 h 替换该位置的值（用更小的值让后面更容易扩展）

### 示例分析

```
输入：[[5,4],[6,4],[6,7],[2,3]]

排序后：[[2,3],[5,4],[6,7],[6,4]]
高度序列：[3, 4, 7, 4]

tails 演化：
h=3: tails=[3]
h=4: tails=[3,4]
h=7: tails=[3,4,7]
h=4: tails=[3,4,7]（替换位置1的4，保持不变）
结果为 3
```

## 复杂度分析

- **时间复杂度：** O(n log n) — 排序 O(n log n) + LIS 遍历 O(n log n)
- **空间复杂度：** O(n) — tails 数组最坏存储所有高度

## Python 解法要点

- 使用 `bisect.bisect_left` 进行二分查找，代码简洁
- `envelopes.sort(key=lambda x: (x[0], -x[1]))` 利用负数实现高度降序
- tails 数组的动态维护体现了耐心排序思想

## Java 解法要点

- `Arrays.sort` 配合自定义 `Comparator` 实现双字段排序
- 手动实现 `lowerBound` 二分查找（Java 标准库 `Collections.binarySearch` 对不存在的 key 返回负值，不如自定义直观）
- 使用 `ArrayList<Integer>` 存储 tails，支持动态扩展和随机访问
