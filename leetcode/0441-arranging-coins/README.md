# 441. Arranging Coins

**难度：** Easy

## 题目描述

你有 `n` 枚硬币，想用它们搭建一个阶梯。阶梯由 `k` 行组成，第 `i` 行恰好有 `i` 枚硬币。最后一行**可能**不完整。

给定整数 `n`，返回**能搭建的完整行数**。

**示例 1：**
```
输入：n = 5
输出：2
解释：因为第 3 行不完整，返回 2
```

**示例 2：**
```
输入：n = 8
输出：3
解释：因为第 4 行不完整，返回 3
```

**约束：** `1 <= n <= 2^31 - 1`

## 解题思路

观察规律：第 `k` 行需要 `k` 枚硬币，前 `k` 行一共需要

$$1 + 2 + 3 + \cdots + k = \frac{k(k+1)}{2}$$

枚硬币。我们要求满足

$$\frac{k(k+1)}{2} \le n$$

的**最大整数** `k`。

把上式整理成标准的一元二次方程：

$$k^2 + k - 2n \le 0$$

由求根公式，正根为

$$k = \frac{-1 + \sqrt{1 + 8n}}{2}$$

直接套公式，把 `n` 代入计算即可。Python 用 `math.sqrt` + 整除 `//`；Java 用 `Math.sqrt` + 强制转 `long` 防溢出，最后转回 `int`。

由于 `n` 最大为 `2^31 - 1`，`8 * n` 在 32 位 int 下会溢出，所以 Java 解法里先把 `n` 转成 `long` 再计算。

## 复杂度分析

- **时间复杂度：** O(1)
- **空间复杂度：** O(1)

## Python 解法要点

- `math.sqrt(1 + 8 * n)` 直接求根，再用 `// 2` 取整。
- Python 整数无大小限制，不会溢出。
- 完整写法可写作 `(math.isqrt(1 + 8 * n) - 1) // 2`，避免浮点误差更稳妥（整数平方根）。

## Java 解法要点

- 必须把 `n` 转 `long`，否则 `8L * n` 在 `n` 接近 `2^31-1` 时会溢出成负数，结果错乱。
- `Math.sqrt` 返回 `double`，开方可能略带浮点误差，但本题数据范围内取整结果稳定。
- 若要严格避免浮点，可以用**二分查找**：在 `[0, n]` 内二分找满足 `k(k+1)/2 <= n` 的最大 `k`，时间 O(log n)，无浮点误差。
