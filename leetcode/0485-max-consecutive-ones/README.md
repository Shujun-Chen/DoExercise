# 485. Max Consecutive Ones

**难度：** Easy

## 题目描述

给定一个二进制数组 `nums`（元素只有 0 或 1），返回数组中连续 1 的最大个数。

示例：
- `nums = [1,1,0,1,1,1]` → 输出 3（最后三个数字是连续的 1）
- `nums = [1,0,1,1,0,1]` → 输出 2

## 解题思路

使用一次遍历 + 双计数器的简单滑动窗口思想：

1. **维护两个变量**：`curCount` 记录当前连续 1 的个数，`maxCount` 记录遍历过程中见过的最大连续 1 的个数。
2. **遍历数组**：
   - 遇到 `1`：`curCount` 加 1，并用 `curCount` 更新 `maxCount`。
   - 遇到 `0`：将 `curCount` 重置为 0（连续的 1 被中断）。
3. **遍历结束**：`maxCount` 即为答案。

## 复杂度分析

- **时间复杂度：** O(n)，只需遍历数组一次。
- **空间复杂度：** O(1)，只使用了两个整型变量。

## Python 解法要点

- 使用 `max()` 函数在每次更新 `curCount` 时同步更新 `maxCount`。
- `if __name__ == "__main__":` 块包含 assert 断言测试，覆盖了全 0、全 1、单个元素等边界情况。

## Java 解法要点

- 使用 `Math.max()` 替代 Python 的 `max()`。
- `main` 方法中同样使用 assert 进行测试，需在运行 Java 时加上 `-ea` 参数启用断言。
