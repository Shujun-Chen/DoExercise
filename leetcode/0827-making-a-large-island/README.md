# 827. Making A Large Island

**难度：** Hard

## 题目描述

给定一个 `n x n` 的二进制矩阵 `grid`，最多可以将其中一个 `0` 变为 `1`。

返回执行该操作后，矩阵中**最大岛屿**的面积。

一个**岛屿**由四个方向（上/下/左/右）相邻的 `1` 组成。

## 解题思路

这道题的关键在于：最多只能改一个格子，所以我们需要：

1. **先识别出所有现存的岛屿**，并记录每个岛屿的大小。
2. **再考虑翻转每个 0**，把翻转后能"桥接"到的不同岛屿的面积合并起来。

具体步骤：

1. **第一次遍历（DFS 染色）**：用一个 `id` 给每个岛屿染色（id 从 2 开始，避开 0/1），同时用数组 `area[id]` 记录每个岛屿的面积。
2. **第二次遍历（尝试翻转每个 0）**：对于每个 0 格子，查看其上下左右四个邻居，把不同 `id` 的岛屿面积加起来再加 1（翻转后的这个格子），取最大值。注意要去重，避免同一个岛屿被重复加。
3. **边界情况**：
   - 如果整个网格都是 `1`，直接返回 `n*n`（不翻转）。
   - 如果整个网格都是 `0`，翻转任何一个 0 都得到面积 1。

这种「先染色、再合并」的两遍扫描模式是处理「最多一次修改求最大连通块」类问题的通用思路。

## 复杂度分析

- **时间复杂度：** O(n²)。第一遍 DFS 染色访问每个格子一次，第二遍扫描每个 0 一次，每次只看 4 个邻居，总体 O(n²)。
- **空间复杂度：** O(n²)。`islandId` 数组与网格等大；递归栈/迭代栈最深 O(n)。

## Python 解法要点

- 使用迭代式 DFS（显式栈）以避免大网格下递归爆栈（n 最大 500）。
- 用一个集合 `seen` 在合并邻居岛屿时去重，避免把同一个岛屿的面积重复相加。
- 用 `max(area.values())` 处理「不翻转任何 0」的情况，避免漏算。
- Python 写法上把方向数组 `dirs` 提到模块顶层，避免每次调用 `dfs` 时重建。

## Java 解法要点

- 用 `int[] area` 数组按 id 直接索引，比 HashMap 更省空间且常数小。
- `Stack` 显式栈做 DFS；`HashSet` 去重（Java 7 兼容写法，不带泛型参数也能编译）。
- `curId` 从 2 开始递增，`area` 数组长度设为 `n*n+2` 足够容纳所有 id。
- 用 `int[] dr/dc` 复用方向偏移，配合 `for (int d = 0; d < 4; d++)` 比写 4 份邻居判断更紧凑。
