# 1013. Partition Array Into Three Parts With Equal Sum

**难度：** Easy

## 题目描述

给定一个整数数组 `arr`，判断能否将数组分成三个**非空**的连续子数组，使得每个子数组的元素和相等。

即：是否存在索引 `i + 1 < j`，使得：
`arr[0] + ... + arr[i] == arr[i+1] + ... + arr[j-1] == arr[j] + ... + arr[n-1]`

## 解题思路

1. **计算总和**：首先遍历数组计算所有元素的总和 `total_sum`。
2. **检查整除性**：如果 `total_sum` 不能被 3 整除，则一定无法平分，直接返回 `false`。
3. **寻找目标和**：`target = total_sum / 3` 是每个部分的目标和。
4. **遍历累加**：从左到右遍历数组，累加部分和。每当部分和等于 `target` 时，计数 +1 并重置累加器。
5. **判定结果**：如果找到至少 3 个和为 `target` 的部分，返回 `true`；否则返回 `false`。

**关键点**：当总和为 0 时，可能会找到超过 3 个和为 0 的部分。此时多余的部分可以合并到第三个部分中，依然满足条件。因此只要找到 ≥ 3 个部分即可。

## 复杂度分析

- **时间复杂度：** O(n) —— 只需遍历数组一次
- **空间复杂度：** O(1) —— 只使用常数个变量

## Python 解法要点

- 使用 `sum(arr)` 计算总和，利用 `%` 检查整除性
- 遍历时累加 `part_sum`，遇到 `target` 时计数 +1 并重置
- 使用 `count >= 3` 作为最终判断条件

## Java 解法要点

- Java 需手动遍历求和，注意 `int` 类型不会溢出（数组长度 ≤ 5×10⁴，数值范围 ±10⁴）
- 使用 `totalSum % 3 != 0` 检查整除性，然后做精确的整数除法
- 找到 3 个部分后可以 `return true` 提前结束，避免多余遍历
- 使用 `assert` 验证测试用例
