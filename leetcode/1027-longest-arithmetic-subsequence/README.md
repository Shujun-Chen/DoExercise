# 1027. Longest Arithmetic Subsequence

**难度：** Medium

## 题目描述
给定一个整数数组 `nums`，返回 `nums` 中最长等差子序列的长度。

注意：
- **子序列** 可以通过删除某些元素（或不删除）得到，不改变剩余元素的顺序。
- 一个序列 `seq` 是 **等差** 的，当且仅当 `seq[i+1] - seq[i]` 的值全部相等（`0 <= i < seq.length - 1`）。

## 解题思路
使用动态规划求解。

1. 定义 `dp[i][diff]` 为以位置 `i` 结尾、公差为 `diff` 的最长等差子序列长度。
2. 对于每个 `i`，遍历所有 `j < i`，计算 `diff = nums[i] - nums[j]`。
3. 以 `j` 结尾的该公差子序列长度为 `dp[j][diff]`（至少为 1，即 `j` 自身），在其基础上加上 `nums[i]` 得到长度 `dp[j][diff] + 1`。
4. 更新 `dp[i][diff]` 为所有可能中的最大值。
5. 全局维护 `ans` 记录最大值。

核心在于：对于每个位置，用一个哈希表存储"公差 -> 最长长度"的映射，避免使用稀疏的二维数组。

## 复杂度分析
- **时间复杂度：** O(n²)，其中 n 为数组长度。需要枚举所有 (i, j) 对。
- **空间复杂度：** O(n²)，最坏情况下每个位置存储 O(n) 个不同公差。

## Python 解法要点
- 使用 `List[Dict[int, int]]` 表示 dp 数组，每个元素是一个 `diff -> length` 的映射。
- `dp[j].get(diff, 1) + 1` 表示在 j 位置的基础上延长一位；若不存在则长度为 1（单个元素）+ 1 = 2。

## Java 解法要点
- 使用 `Map<Integer, Integer>[]` 数组，因泛型不能直接创建 `HashMap[n]`，需要逐个初始化。
- 使用 `getOrDefault(diff, 1)` 优雅处理差值的缺失情况。
