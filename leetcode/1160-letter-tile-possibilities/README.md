# 1160. Letter Tile Possibilities

**难度：** Medium

## 题目描述

你有一套瓷砖，每块瓷砖上印有一个字母 `tiles[i]`。返回使用这些瓷砖上的字母可以组成的所有非空字母序列的数量。

**示例 1：**

```
输入：tiles = "AAB"
输出：8
解释：可能的序列为 "A", "B", "AA", "AB", "BA", "AAB", "ABA", "BAA"。
```

**示例 2：**

```
输入：tiles = "AAABBC"
输出：188
```

**示例 3：**

```
输入：tiles = "V"
输出：1
```

**约束条件：**
- `1 <= tiles.length <= 7`
- `tiles` 仅由大写英文字母组成。

## 解题思路

这道题的核心是**统计所有非空子序列的排列数量**，且需要处理**重复字母**的情况。

### 方法：回溯法 + 频率统计

1. **频率数组**：统计每个字母（A-Z）的出现次数。
2. **DFS 回溯**：
   - 遍历 26 个字母，对每个可用（计数 > 0）的字母：
     - 使用它（计数减 1）
     - 每用掉一个字母就产生了一个新序列，计数 +1
     - 继续递归探索更多组合
     - 回溯恢复计数
3. 返回总数。

这个方法的精髓在于：**每个递归层级的每个可用字母代表一个序列结尾的选择**，遍历所有可能性即得到总数。

### 为什么用频率而非集合去重？

如果直接用 `Set<String>` 收集所有序列，对于 `tiles.length = 7` 最多有 7! = 5040 种排列，加上子序列组合，总数约 13699（对于 "AAABBC" 是 188），用集合完全可以承受。但频率计数法更高效——无需生成实际字符串，直接计数即可。

## 复杂度分析

- **时间复杂度：** O(2^n)，其中 n = tiles.length。每个字母在每个递归层级有两种选择（使用或不使用），实际运行远小于理论最坏情况，因为重复字母减少了分支数。
- **空间复杂度：** O(n)，递归栈的最大深度为 n。

## Python 解法要点

- 用 `freq = [0] * 26` 统计字母频率
- `backtrack()` 函数递归计数，注意 `freq[i] -= 1` 后要加回
- Python 的 `ord(ch) - ord('A')` 将字母映射到数组索引

## Java 解法要点

- 用 `int[26]` 数组统计频率
- `private int backtrack(int[] freq)` 辅助方法递归计数
- 注意 freq 数组在递归中会被修改，需要正确的回溯恢复
