# 1200. Minimum Absolute Difference

**难度：** Easy

## 题目描述

给定一个由**互不相同**的整数组成的数组 `arr`，找出所有具有最小绝对差的元素对。返回按升序排列的元素对列表，每个元素对 `[a, b]` 满足：
- `a` 和 `b` 来自 `arr`，且 `a < b`
- `b - a` 等于 `arr` 中任意两个元素的最小绝对差

## 解题思路

**核心观察：** 对于排序后的数组，任意两个元素的最小绝对差一定出现在相邻元素之间。

**证明：** 假设 `arr` 已排序，取任意不相邻的两个元素 `arr[i]` 和 `arr[j]`（`i < j`），存在元素 `arr[i+1]` 满足 `arr[i] < arr[i+1] < arr[j]`，因此 `arr[i+1] - arr[i] < arr[j] - arr[i]`，即相邻差值更小。所以全局最小绝对差必来自相邻元素。

**算法步骤：**

1. 对数组进行升序排序
2. 遍历排序后的数组，计算每对相邻元素的差值，记录最小差值 `minDiff`
3. 再次遍历排序后的数组，收集所有差值等于 `minDiff` 的相邻元素对
4. 返回结果（由于数组已排序，结果自然按升序排列）

以 **示例 1** 为例：
```
arr = [4, 2, 1, 3]
排序后 → [1, 2, 3, 4]
相邻差：2-1=1, 3-2=1, 4-3=1 → minDiff = 1
结果：[[1,2], [2,3], [3,4]]
```

## 复杂度分析

- **时间复杂度：** O(N log N) — 排序占主导，两次线性扫描均为 O(N)
- **空间复杂度：** O(N) — 结果列表在最坏情况下包含 N-1 个元素对（当所有相邻差相等时）

## Python 解法要点

- 使用 `arr.sort()` 原地排序
- 两次遍历：第一次找最小差值，第二次收集结果对
- 利用排序后相邻元素自然满足 `a < b` 的性质

## Java 解法要点

- 使用 `Arrays.sort(arr)` 原地排序
- 用 `Arrays.asList(a, b)` 快速创建结果对
- 结果类型为 `List<List<Integer>>`，与 LeetCode 方法签名一致
