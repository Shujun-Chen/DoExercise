# 1282. Group the People Given the Group Size They Belong To

**难度：** Medium

## 题目描述

给定 n 个人，每个人有一个组大小 groupSizes[i]，表示该人必须在大小为 groupSizes[i] 的组中。返回所有组的列表，使得每个人恰好出现在一个大小正确的组中。

例如，如果 groupSizes[1] = 3，则人 1 必须在大小为 3 的组中。每个组中的所有人 ID 会出现在输出列表的一个子列表中。

## 解题思路

1. **按组大小分组**：使用字典（HashMap），以组大小为 key，收集对应需要该组大小的人员 ID
2. **满桶即输出**：当某个组大小的人员数量恰好等于该组大小时，将当前收集的人员形成一个完整的组加入结果
3. **清空桶**：形成组后清空该组大小对应的人员列表，继续收集下一批
4. 遍历结束后，所有人恰好被分配到正确大小的组中

## 复杂度分析

- **时间复杂度：** O(n)，其中 n 是人数，只需遍历一次数组
- **空间复杂度：** O(n)，字典最多存储 n 个元素

## Python 解法要点

- 使用字典 `size_to_people` 将人员按组大小归类
- 当字典中某组大小的人员数达到该大小时，立即形成一个组并重置
- 代码简洁直观，利用 enumerate 同时获取索引和值

## Java 解法要点

- 使用 `HashMap<Integer, List<Integer>>` 存储分组信息
- `putIfAbsent` 方法简化了空值检查
- 形成组后重新创建一个新的 ArrayList，避免修改已添加到结果的列表
