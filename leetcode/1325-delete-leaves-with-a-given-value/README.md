# 1325. Delete Leaves With a Given Value

**难度：** Medium

## 题目描述

给定一棵二叉树 `root` 和一个整数 `target`，删除所有值为 `target` 的叶子节点。

注意：一旦你删除了一个值为 `target` 的叶子节点，如果它的父节点变成了叶子节点且值也为 `target`，那么也应该被删除（需要持续执行直到无法再删除为止）。

## 解题思路

本题的关键在于理解"删除叶子后，父节点可能变成新的叶子"这一连锁反应。

### 后序遍历（推荐）

1. 使用**后序遍历**（左 -> 右 -> 根）遍历二叉树
2. 先递归处理左右子树，确保子节点先被检查和处理
3. 处理完子树后，检查当前节点：
   - 如果左右子树都为空（即当前节点是叶子）且 `val == target`，返回 `None`（删除）
   - 否则保留当前节点

为什么用后序遍历？因为必须先处理完子节点，才能判断当前节点是否变成了叶子。如果用前序遍历，可能会漏掉因子节点被删除后才变成叶子的情况。

### 举例说明（示例 3）

```
输入: [1,2,null,2,null,2], target = 2

原始树:        1
              /
             2       <- 中间的 2 不是叶子，先不删
            /
           2         <- 叶子，val=2，删除
          /
         2           <- 叶子，val=2，删除

后序遍历过程：
- 最底层 2（叶子）-> 删除
- 上一层 2 变成叶子 -> 删除
- 再上一层 2 变成叶子 -> 删除
- 根节点 1 保留
输出: [1]
```

## 复杂度分析
- **时间复杂度：** O(n)，每个节点恰好访问一次
- **空间复杂度：** O(h)，递归调用栈的深度等于树的高度 h（最坏情况退化为链表 O(n)，平衡树为 O(log n)）

## Python 解法要点
- 使用 `Optional[TreeNode]` 类型注解
- 后序遍历：先递归修改 `root.left` 和 `root.right`，再判断当前节点
- 当叶子节点值等于 target 时返回 `None`
- 辅助函数 `build_tree_from_list` 和 `tree_to_list` 用于测试

## Java 解法要点
- 后序遍历递归结构与 Python 一致
- 使用 `Queue` 进行层序建树和层序序列化
- 空值判断使用 `== null`
- `main` 方法包含三个测试用例的验证
