# 1389. Create Target Array in the Given Order

**难度：** Easy

## 题目描述

给定两个整数数组 `nums` 和 `index`，按要求创建目标数组。规则如下：
- 初始时目标数组为空
- 从左到右依次读取 `nums[i]` 和 `index[i]`，在目标数组下标 `index[i]` 处插入值 `nums[i]`
- 重复上述步骤直到读完所有元素
- 返回最终的目标数组

## 解题思路

题目要求模拟一个按指定位置依次插入元素的过程。每次插入时，`index[i]` 就是当前目标数组中要插入的位置。

**核心思路：直接模拟**

1. 初始化一个空列表 `target`
2. 遍历 `i` 从 0 到 n-1：
   - 在 `target` 的下标 `index[i]` 处插入 `nums[i]`（利用语言内置的 insert 方法）
3. 返回最终的 `target`

以 **示例 1** 为例：
```
nums  = [0, 1, 2, 3, 4]
index = [0, 1, 2, 2, 1]

i=0: 在位置0插入0 → [0]
i=1: 在位置1插入1 → [0, 1]
i=2: 在位置2插入2 → [0, 1, 2]
i=3: 在位置2插入3 → [0, 1, 3, 2]   ← 2被后移
i=4: 在位置1插入4 → [0, 4, 1, 3, 2] ← 1,3,2被后移
```

## 复杂度分析

- **时间复杂度：** O(n²) — 每次 `insert` 操作在最坏情况下需要移动 O(n) 个元素，共 n 次操作
- **空间复杂度：** O(n) — 结果数组占用线性空间

## Python 解法要点

- 使用 `list.insert(pos, val)` 直接实现在指定位置插入，内部会自动将后续元素后移，无需手动处理

## Java 解法要点

- 使用 `ArrayList` 的 `add(index, element)` 方法在指定位置插入
- 最后将 `ArrayList<Integer>` 转换为 `int[]` 返回
