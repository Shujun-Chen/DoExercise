# 1406. Stone Game III

**难度：** Hard

## 题目描述

Alice 和 Bob 在一排石头上玩游戏，每块石头有一个整数值（可正可负）。两人轮流从剩余石头的最前面取 1、2 或 3 块，Alice 先手。双方都以最优策略行动。得分高的玩家获胜，得分相同则平局。返回 "Alice"、"Bob" 或 "Tie"。

**约束条件：**
- `1 <= stoneValue.length <= 5 * 10^4`
- `-1000 <= stoneValue[i] <= 1000`

## 解题思路

这是一个经典的**博弈 DP** 问题，核心思想是：从后往前计算每个位置的"分差"（当前玩家得分 - 对手得分）。

**步骤：**

1. **定义状态：** `dp[i]` 表示从位置 `i` 开始，当前玩家能获得的最大分差（当前玩家得分 - 对手得分）。

2. **状态转移：** 当前玩家可以取 1、2 或 3 堆石头：
   - 取 1 堆：分差 = `stoneValue[i] - dp[i+1]`
   - 取 2 堆：分差 = `(stoneValue[i] + stoneValue[i+1]) - dp[i+2]`
   - 取 3 堆：分差 = `(stoneValue[i] + stoneValue[i+1] + stoneValue[i+2]) - dp[i+3]`
   
   取三者中的最大值：`dp[i] = max(以上三种选择)`

3. **解释：** 当前玩家取了 k 堆后，对手从 `i+k` 开始取，对手的分差是 `dp[i+k]`。当前玩家这一轮的得分减去对手后续的最优分差，就是当前玩家的净分差。

4. **空间优化：** 由于 `dp[i]` 只依赖 `dp[i+1]`、`dp[i+2]`、`dp[i+3]`，可以用三个变量滚动代替数组。

5. **最终判断：**
   - `dp[0] > 0` → Alice 赢
   - `dp[0] < 0` → Bob 赢
   - `dp[0] == 0` → 平局

## 复杂度分析

- **时间复杂度：** O(n)，每个位置只遍历一次，内层循环固定为 3
- **空间复杂度：** O(1)，只使用三个滚动变量

## Python 解法要点

- 使用三个变量 `dp[0]`、`dp[1]`、`dp[2]` 分别对应 `dp[i+1]`、`dp[i+2]`、`dp[i+3]`
- 从后往前遍历，每步计算当前最优分差后滚动更新
- `float('-inf')` 初始化确保负值石头也能正确处理

## Java 解法要点

- 三个 `int` 变量 `dp1`、`dp2`、`dp3` 滚动
- `Integer.MIN_VALUE` 初始化最优值
- `assert` 语句用于验证，运行时需加 `-ea` 参数
