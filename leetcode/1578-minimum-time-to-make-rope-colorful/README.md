# 1578. Minimum Time to Make Rope Colorful

**难度：** Medium

## 题目描述

Alice 的绳子上有 `n` 个气球排成一排，用字符串 `colors` 描述每个气球颜色。Bob 可以移除气球，移除第 `i` 个气球需要 `neededTime[i]` 秒。

要求绳子"色彩缤纷"——相邻两个气球颜色不同。求 Bob 让绳子色彩缤纷所需的**最少**时间。

## 解题思路

这是一道典型的**贪心**题。关键观察：

- 题目只关心**相邻**颜色是否相同，所以把 `colors` 按相邻同色划分为若干"组"（连续相同颜色的段）。
- 在同一组里，**至少**要移除掉除一个以外的全部气球。要让总时间最少，自然**保留 neededTime 最大的那一个**，移除其余的。
- 因此一组的花费 = `组内 neededTime 总和 - 组内最大值`。若组内只有一个元素（长度为 1），则无需移除，花费为 0。

算法步骤：
1. 遍历 `colors`，用双指针找出所有连续同色段。
2. 对每段累加 `neededTime`，同时记录最大值。
3. 若段长 > 1，累加 `sum - max` 到答案。
4. 指针跳到下一段开头继续处理。

正确性：因为只比较同一段内移除谁，而不同段之间不会互相影响（段边界颜色一定不同），各段决策独立，贪心成立。

## 复杂度分析

- **时间复杂度：** O(n)，单次遍历。
- **空间复杂度：** O(1)，仅使用常数级额外变量。

## Python 解法要点

- 用 `while` + 双指针（`i`、`j`）划段，逻辑直观。
- `i = j` 一次性跳过整段，避免逐元素比较。
- `if __name__ == "__main__"` 内置 5 个测试，覆盖：标准用例、本就 colorful、两端同色、两个同色、全部同色。

## Java 解法要点

- 用 `colors.charAt(j) == colors.charAt(i)` 比较字符。
- 段内循环累加 `sum` 与维护 `max`，同样 O(n)。
- `main` 方法中用 `assert` 做自检，并打印每个用例的实际输出便于排查。
