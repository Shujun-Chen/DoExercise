# 1835. Find XOR Sum of All Pairs Bitwise AND

**难度：** Hard

## 题目描述
给定两个仅包含非负整数的数组 `arr1` 和 `arr2`。对每一对下标 `(i, j)` 计算 `arr1[i] AND arr2[j]`，并将所有结果进行按位异或，返回最终的异或和。

例如，`arr1 = [1, 2, 3]`、`arr2 = [6, 5]` 时，所有按位与结果为 `[0, 1, 2, 0, 2, 1]`，它们的异或和为 `0`。

## 解题思路
利用按位与对按位异或的分配律：

```text
(a AND b) XOR (a AND c) = a AND (b XOR c)
```

1. 固定 `arr1[i]`，将它与 `arr2` 中所有元素的按位与结果异或，可以化简为：
   `arr1[i] AND (arr2[0] XOR arr2[1] XOR ...)`。
2. 再对所有 `arr1[i]` 对应的结果异或，同样应用分配律，最终得到：
   `(arr1[0] XOR arr1[1] XOR ...) AND (arr2[0] XOR arr2[1] XOR ...)`。
3. 因此只需分别求两个数组的整体异或值，再将二者按位与，无需枚举全部数对。

## 复杂度分析
- **时间复杂度：** O(n + m)，其中 `n` 和 `m` 分别是两个数组的长度
- **空间复杂度：** O(1)

## Python 解法要点
分别用循环累计 `arr1` 和 `arr2` 的异或值，最后返回二者的按位与。整个过程只使用两个整数变量。

## Java 解法要点
使用增强 `for` 循环分别计算两个数组的异或值。Java 的 `int` 足以容纳题目范围内不超过 `10^9` 的非负整数及其位运算结果。
