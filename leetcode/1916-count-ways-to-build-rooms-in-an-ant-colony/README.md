# 1916. Count Ways to Build Rooms in an Ant Colony

**难度：** Hard

## 题目描述

你是一只蚂蚁，负责给蚁群建造编号从 `0` 到 `n-1` 的 `n` 个新房间。你有一个扩建计划 `prevRoom`（0-indexed 整数数组），其中 `prevRoom[i]` 表示在建造房间 `i` 之前必须先建造房间 `prevRoom[i]`，且这两个房间必须直接相连。房间 `0` 已经建好，因此 `prevRoom[0] = -1`。

每次只能建造一个房间，且只能在已建造的相邻房间之间自由通行。返回建造所有房间的**不同顺序数**，结果对 `10^9 + 7` 取模。

## 解题思路

1. **建树：** `prevRoom` 数组定义了一棵以 `0` 为根的树，每个节点（除根外）的父节点就是 `prevRoom[i]`
2. **组合公式：** 建造顺序数 = `n! / (∏ subtree_size[v])`，其中 `subtree_size[v]` 是节点 `v` 的子树大小
3. **公式推导：** 考虑树中每个节点，它的子孙必须在它之后建造，但不同子树之间可以交错排列。利用组合数的递推关系可以证明这个公式
4. **模运算：** 由于需要取模，除法需要用费马小定理转换为乘法逆元：`a / b ≡ a × b^(p-2) (mod p)`
5. **计算步骤：**
   - DFS 计算每个节点的子树大小
   - 计算 `n! mod p`
   - 计算所有子树大小的乘积 `mod p`
   - 用快速幂求逆元，相乘得到答案

## 复杂度分析

- **时间复杂度：** O(n)，包括一次 DFS 遍历和一次快速幂运算
- **空间复杂度：** O(n)，用于存储树结构和子树大小数组

## Python 解法要点

- 使用显式栈进行 DFS，避免递归深度限制
- 利用 `pow(x, MOD-2, MOD)` 内置函数计算模逆元
- 默认 dict 构建邻接表，代码简洁

## Java 解法要点

- 使用 `ArrayDeque` 作为显式栈，手动管理 DFS 状态
- 自定义 `modPow` 快速幂函数实现模逆元
- `long` 类型防止中间结果溢出
