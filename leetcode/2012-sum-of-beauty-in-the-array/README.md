# 2012. Sum of Beauty in the Array

**难度：** Medium

## 题目描述

给定一个 **0 索引** 的整数数组 `nums`。对于每个索引 `i`（`1 <= i <= nums.length - 2`），`nums[i]` 的 **美丽值** 定义为：

- **2**：如果 `nums[j] < nums[i] < nums[k]` 对于 **所有** `0 <= j < i` 和 **所有** `i < k <= nums.length - 1` 成立。
- **1**：如果 `nums[i - 1] < nums[i] < nums[i + 1]`，且上一个条件不满足。
- **0**：如果上述条件均不满足。

返回所有 `nums[i]` 的美丽值之和。

## 解题思路

核心在于高效判断每个位置是否「严格大于左侧所有数」且「严格小于右侧所有数」。暴力做法是 O(n²)，但通过预处理可以优化到 O(n)。

**分两步走：**

1. **预处理左右极值**
   - `leftMax[i]`：记录 `nums[0..i-1]` 的最大值（即 i 左侧所有元素的最大值）
   - `rightMin[i]`：记录 `nums[i+1..n-1]` 的最小值（即 i 右侧所有元素的最小值）
   - 分别从左到右和从右到左扫描各一次即可得到

2. **按规则计算美丽值**
   - 对于每个 `i`（1 到 n-2）：
     - 若 `leftMax[i] < nums[i] < rightMin[i]` → 加 2（条件2）
     - 否则若 `nums[i-1] < nums[i] < nums[i+1]` → 加 1（条件1）

## 复杂度分析

- **时间复杂度：** O(n)
  - 两次线性扫描（n 为数组长度），一次遍历计算结果
- **空间复杂度：** O(n)
  - 需要两个长度为 n 的辅助数组

## Python 解法要点

- 使用 `List[int]` 类型提示
- 先预处理 `left_max` 和 `right_min` 数组，再遍历计算
- 注意条件判断的顺序：先判断条件2（全局），再判断条件1（局部）

## Java 解法要点

- 类名必须为 `Solution`，方法签名与原题一致
- 使用 `Math.max` / `Math.min` 进行极值计算
- `main` 方法中包含测试用例验证
