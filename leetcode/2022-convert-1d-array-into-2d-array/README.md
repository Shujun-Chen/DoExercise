# 2022. Convert 1D Array Into 2D Array

**难度：** Easy

## 题目描述

给定一个 **0-indexed** 的一维整数数组 `original` 和两个整数 `m` 和 `n`，你需要使用 `original` 中的 **所有** 元素创建一个 `m` 行 `n` 列的二维数组。

规则：
- `original` 中索引 `0` 到 `n-1`（包含）的元素构成二维数组的第一行
- `original` 中索引 `n` 到 `2n-1`（包含）的元素构成第二行，以此类推

返回按照上述过程构造的 `m × n` 二维数组，如果不可能则返回空二维数组。

## 解题思路

这是一道简单的数组模拟题：

1. **边界检查**：首先检查 `original` 的长度是否等于 `m * n`，如果不相等则无法构建，直接返回空数组
2. **按行切片**：遍历 `m` 行，每次从 `original` 中取 `n` 个元素作为一行
3. **构建结果**：使用 Python 的切片操作 `original[i*n : (i+1)*n]` 提取每一行

核心公式：
- 第 `i` 行的元素范围：`original[i*n]` 到 `original[(i+1)*n - 1]`

## 复杂度分析

- **时间复杂度：** O(m × n) = O(len(original))，需要遍历所有元素一次
- **空间复杂度：** O(m × n) = O(len(original))，输出的二维数组空间

## Python 解法要点

- 使用列表切片 `original[i*n : (i+1)*n]` 高效提取每一行
- 代码简洁，一行切片即可完成一行的构建
- 注意类型标注使用 `List[List[int]]`

## Java 解法要点

- 使用双重循环构建二维数组
- 外层循环遍历行，内层循环填充每列
- 元素索引映射：`result[i][j] = original[i * n + j]`
- 不匹配时返回 `new int[0][0]`（空数组）
