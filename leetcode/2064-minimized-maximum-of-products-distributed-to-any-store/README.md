# 2064. Minimized Maximum of Products Distributed to Any Store

**难度：** Medium

## 题目描述

给你一个整数 `n` 表示有 n 家专卖店，以及一个整数数组 `quantities` 表示 m 种产品的数量。你需要将所有产品分配到零售店，遵循以下规则：

- 每家店铺最多只能分配一种产品类型，但可以分配任意数量。
- 设 `x` 表示分配给任何一家店铺的最大产品数，你需要最小化这个 `x`。

返回最小可能的 `x`。

## 解题思路

这是一道典型的**二分查找答案（Binary Search on Answer）**问题。

### 关键观察

1. 如果每个店铺最多分 `x` 件产品，对于数量为 `q` 的产品类型，需要 `ceil(q / x)` 个店铺来分配。
2. 如果所有产品所需的总店铺数 ≤ `n`，则 `x` 是一个可行解。
3. `x` 越大越容易可行（单调性），因此可以用二分查找找到最小可行的 `x`。

### 算法步骤

1. 二分查找范围：`[1, max(quantities)]`
   - 下界 1：每个店铺至少分 1 件
   - 上界 max(quantities)：最坏情况是所有产品都给一个店
2. 对每个中间值 `mid`，检查是否可行：
   - 遍历 `quantities`，计算 `sum(ceil(q / mid))`
   - 如果总和 ≤ `n`，说明 `mid` 可行，尝试更小值
   - 否则需要更大的 `mid`
3. 返回左边界（最小可行值）

## 复杂度分析

- **时间复杂度：** O(m × log M)
  - m = len(quantities)，M = max(quantities)
  - 二分查找 log M 次，每次遍历数组 O(m)
- **空间复杂度：** O(1)
  - 只使用了常数个额外变量

## Python 解法要点

- 使用 `(q + x - 1) // x` 实现向上取整
- 提前剪枝：如果店铺数已超过 n 立即返回 False
- 使用 `List[int]` 类型提示（需从 typing 导入）

## Java 解法要点

- 使用 `(q + x - 1) / x` 实现向上取整
- 二分查找使用 `lo + (hi - lo) / 2` 避免溢出
- 使用 `Math.max` 求 quantities 的最大值
