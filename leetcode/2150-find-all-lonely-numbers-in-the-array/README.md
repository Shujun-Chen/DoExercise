# 2150. Find All Lonely Numbers in the Array

**难度：** Medium

## 题目描述

给定一个整数数组 `nums`。如果一个数字 `x` 满足以下条件，则称它是**孤独**的：
1. 它在数组中出现**恰好一次**
2. 它的相邻数字 `x-1` 和 `x+1` 都不在数组中

返回数组中所有孤独的数字。可以按任意顺序返回。

**示例 1：**
```
输入：nums = [10,6,5,8]
输出：[10,8]
解释：
- 10 出现一次，且 9 和 11 都不在数组中 → 孤独
- 8 出现一次，且 7 和 9 都不在数组中 → 孤独
- 5 出现一次，但 6 在数组中 → 不孤独
- 6 出现一次，但 5 在数组中 → 不孤独
```

**示例 2：**
```
输入：nums = [1,3,5,3]
输出：[1,5]
解释：
- 1 出现一次，且 0 和 2 都不在数组中 → 孤独
- 5 出现一次，且 4 和 6 都不在数组中 → 孤独
- 3 出现了两次 → 不孤独
```

**约束条件：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^6`

## 解题思路

这道题的核心在于同时满足两个条件：出现次数为 1，且相邻数字不存在。

### 步骤分解

1. **统计频率**：使用哈希表（`Counter` / `HashMap`）统计每个数字的出现次数，一趟遍历完成。
2. **筛选孤独数字**：遍历哈希表的键值对，对每个数字 `x`：
   - 检查 `freq[x] == 1`（恰好出现一次）
   - 检查 `x-1` 和 `x+1` 是否都不在哈希表中
   - 同时满足则加入结果集

### 关键点

- 为什么用哈希表而不是排序？因为相邻数字只需要检查 `x±1`，不需要排序。哈希表 O(1) 查询是最高效的。
- 约束中值范围较大（0~10^6），但不影响，因为哈希表只存储实际出现的数字。
- `nums.length` 最大 10^5，哈希表空间完全可行。

## 复杂度分析

- **时间复杂度：** O(n) — 两次线性遍历（一次统计频率，一次筛选），n 为数组长度
- **空间复杂度：** O(n) — 哈希表存储最多 n 个不同的数字

## Python 解法要点

- 使用 `collections.Counter` 一行完成频率统计
- 遍历字典的 `items()`，同时获取数字和次数
- 用 `not in freq` 检查相邻数字是否不存在

## Java 解法要点

- 使用 `HashMap<Integer, Integer>` 统计频率
- 遍历 `entrySet()` 获取键值对
- 用 `!freq.containsKey(x ± 1)` 检查相邻数字
- 返回 `ArrayList<Integer>` 作为结果
