# 2260. Divide a String Into Groups of Size k

**难度：** Easy

## 题目描述

给定一个字符串 `s`，按以下规则将其分组：

- 每 `k` 个连续字符组成一组。
- 如果最后一组的字符数不足 `k` 个，则用字符 `fill` 补齐。
- 返回所有组组成的字符串数组。

## 解题思路

本题为简单的字符串模拟题，核心思路：

1. **步长遍历**：以 `k` 为步长遍历字符串，每次取 `[i, i + k)` 的子串。
2. **填充处理**：如果取出的子串长度小于 `k`（即最后一组不足），在末尾追加 `fill` 字符直到长度达到 `k`。
3. **返回结果**：将所有组按顺序放入结果列表中返回。

### 关键点

- 使用 Python 切片语法 `s[i:i+k]` 可以自动处理末尾剩余不足 k 的情况。
- 字符串补全使用 Python 的乘法运算符：`fill * (k - len(part))`，简洁高效。
- 注意遍历起始为 0，步长为 k，不要漏掉中间元素。

## 复杂度分析

- **时间复杂度：** O(n)，其中 n 为字符串长度，只需一次线性遍历。
- **空间复杂度：** O(n / k) 用于存储结果列表。每组固定长度 k，共 n/k 组（向上取整）。

## Python 解法要点

- 使用 `range(0, n, k)` 步长循环。
- 通过 `s[i:i+k]` 切片获取每组字符。
- 补全时使用字符串乘法 `fill * (k - len(part))`。

## Java 解法要点

- 使用 `for (int i = 0; i < n; i += k)` 步长循环。
- 使用 `s.substring(i, Math.min(i + k, n))` 切分。
- 补全时使用 `StringBuilder` 逐个追加 fill 字符。
