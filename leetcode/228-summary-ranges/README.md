# 228. Summary Ranges

**难度：** Easy

## 题目描述

给定一个已经按升序排列且没有重复元素的整数数组 `nums`，将其中连续的数字汇总成尽可能少的区间。长度大于 1 的区间表示为 `a->b`，只有一个数字的区间直接表示为该数字。

## 解题思路

1. 用 `start` 记录当前连续区间的起点。
2. 从第二个元素开始遍历数组；当遍历到数组末尾，或当前数字不等于前一个数字加一时，说明当前区间结束。
3. 如果区间只有一个元素，加入该元素；否则加入起点和终点组成的 `start->end`。
4. 将 `start` 移动到下一个尚未处理的数字，继续遍历。

## 复杂度分析

- **时间复杂度：** O(n)，其中 n 为数组长度，每个元素只被访问一次。
- **空间复杂度：** O(n)，用于保存返回结果；不计返回结果时为 O(1)。

## Python 解法要点

使用 `range(1, len(nums) + 1)` 遍历，并把 `i == len(nums)` 作为哨兵条件，从而统一处理最后一个连续区间，避免遍历结束后额外补逻辑。

## Java 解法要点

使用 `ArrayList<String>` 保存区间。判断连续性时将整数提升为 `long`，避免前一个数字为 `Integer.MAX_VALUE` 时执行 `nums[i - 1] + 1` 发生整数溢出。
