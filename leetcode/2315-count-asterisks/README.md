# 2315. Count Asterisks

**难度：** Easy

## 题目描述

给你一个字符串 `s`，其中每两个连续的竖线 `'|'` 被分组为一对。换言之，第 1 个和第 2 个 `'|'` 组成一对，第 3 个和第 4 个 `'|'` 组成一对，以此类推。

请你返回**不在**竖线对之间（即不在任何一对 `'|'` 内部）的 `'*'` 的数量。

注意：每个 `'|'` 只属于恰好一对。

**示例 1：**
```
输入: s = "l|*e*et|c**o|*de|"
输出: 2
解释: 不在竖线对之间的 '*' 是第 1 个和第 9 个 '*'.
```

**示例 2：**
```
输入: s = "iamprogrammer"
输出: 0
解释: 字符串中没有竖线。
```

**示例 3：**
```
输入: s = "yo|uar|e**|b|e***au|tifu|l"
输出: 5
解释: 需要计数的 '*' 是第 1、2、3、4、5 个 '*'.
```

## 解题思路

核心思想是使用一个**开关标志**来追踪当前是否在竖线对的内部。

### 方法一：奇数/偶数开关

用一个变量 `bars` 记录已经遇到的竖线数量：
- 当 `bars` 为偶数时，当前处于竖线对**外部**：遇到的 `'*'` 需要计数
- 当 `bars` 为奇数时，当前处于竖线对**内部**：遇到的 `'*'` 跳过

遍历字符串一遍即可得到答案。

### 方法二：XOR 翻转

用 `ok` 标志位，遇到 `'|'` 时 `ok ^= 1`（翻转），遇到 `'*'` 时 `ans += ok`。

## 复杂度分析

- **时间复杂度：** O(n)，其中 n 为字符串长度，只需遍历一次
- **空间复杂度：** O(1)，仅使用常数个变量

## Python 解法要点

- 使用 `bars % 2 == 0` 判断是否在外部
- 直接遍历字符串字符，不需要 index
- `if __name__ == "__main__"` 中编写测试用例

## Java 解法要点

- 使用 `bars % 2 == 0` 判断外部状态
- 用 `s.charAt(i)` 遍历字符串
- `main` 方法中用 `assert` 验证测试用例
