# 236. Lowest Common Ancestor of a Binary Tree

**难度：** Medium

## 题目描述

给定一个二叉树（无父指针），找到两个指定节点 `p` 和 `q` 的最近公共祖先（LCA）。

最近公共祖先的定义：`p` 和 `q` 可以是自身的后代（含自身），LCA 是这两个节点后代中深度最大的那一个。

**示例 1：**
```
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3。
```

**示例 2：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5（因为 5 自身也可以是 4 的祖先）。
```

**约束：**
- 树中节点数在 `[2, 10^5]` 之间
- 所有节点值唯一
- `p != q`
- `p` 和 `q` 一定存在于树中

## 解题思路

后序遍历（自底向上）—— 这道题的精髓在于**自底向上**传播 LCA。

1. **递归终止条件**：当前节点为空直接返回 `None`；如果当前节点恰好是 `p` 或 `q`，返回当前节点（命中即返回）。
2. **后序处理**：递归地查询左右子树，分别得到 `left` 和 `right`。
3. **合并结果**：
   - `left` 和 `right` 都非空 → `p` 和 `q` 分别在左右子树，当前节点就是 LCA。
   - 仅一侧非空 → `p` 和 `q` 都在那一侧，LCA 就在那一侧返回的结果里。
   - 都为空 → 当前子树不含 `p`/`q`，返回 `None`。

由于后序遍历先访问子节点再访问父节点，LCA 信息会从子节点一路"冒泡"上来，第一次同时看到两个命中点的位置就是答案。

## 复杂度分析

- **时间复杂度：** `O(n)`，每个节点最多访问一次。
- **空间复杂度：** `O(h)`，递归栈深度由树高 `h` 决定，最坏（链状树）`O(n)`。

## Python 解法要点

- 把 `TreeNode` 定义放在文件里，方便本地单测；LeetCode 平台会跳过这个定义。
- 利用短路：当 `root is p` 或 `root is q` 时直接返回 `root`，省去对子树的进一步搜索。
- `find_node` / `build_tree` 这两个辅助函数只在 `__main__` 里被调用，对线上判题没有副作用。
- 测试覆盖了：官方两个示例、祖先关系、单节点树、左偏长链这四类边界场景。

## Java 解法要点

- Java 版同样把 `TreeNode` 定义内嵌到文件里，避免本地编译时找不到类。
- 使用三元运算符 `left != null ? left : right` 让代码更紧凑；语义和 Python 版完全一致。
- `buildTree` 用 `Integer[]` 而不是 `int[]`，便于在层序构造时插入 `null` 表示空位。
- `main` 方法中以 `assert` 形式做断言，运行前需加 `-ea`（IDEA 默认开启，命令行则 `java -ea Solution`）。
