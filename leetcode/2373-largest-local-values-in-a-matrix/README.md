# 2373. Largest Local Values in a Matrix

**难度：** Easy

## 题目描述

给定一个 n×n 的整数矩阵 `grid`，生成一个大小为 (n-2)×(n-2) 的整数矩阵 `maxLocal`，使得 `maxLocal[i][j]` 等于 `grid` 中以第 i+1 行、第 j+1 列为中心的 3×3 子矩阵中的最大值。换句话说，我们需要找出 `grid` 中每个连续 3×3 子矩阵的最大值。

## 解题思路

1. **确定结果矩阵大小**：输入为 n×n，输出为 (n-2)×(n-2)
2. **暴力遍历**：对于输出矩阵的每个位置 `(i, j)`，对应原矩阵中以 `(i, j)` 为左上角的 3×3 子矩阵
3. **求窗口最大值**：遍历 3×3 窗口中的 9 个元素，取最大值存入结果矩阵
4. 返回结果矩阵

## 复杂度分析

- **时间复杂度：** O(n²)，共 (n-2)² 个窗口，每个窗口检查 9 个元素（常数），整体为 O(n²)
- **空间复杂度：** O(n²)，输出矩阵大小为 (n-2)×(n-2)

## Python 解法要点

- 使用列表推导创建结果矩阵
- 四层循环：外两层遍历窗口位置，内两层遍历 3×3 窗口内元素
- 每个窗口的 9 个元素比较取最大值

## Java 解法要点

- 使用二维数组直接创建结果矩阵
- 使用 `Math.max()` 比较取最大值
- 使用 `Arrays.deepEquals()` 进行二维数组的断言比较
