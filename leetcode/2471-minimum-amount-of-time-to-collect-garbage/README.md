# 2471. Minimum Amount of Time to Collect Garbage

**难度：** Medium

## 题目描述
给定一个字符串数组 `garbage`，`garbage[i]` 表示第 i 栋房子的垃圾种类组合，只包含字符 `'M'`（金属）、`'P'`（纸张）、`'G'`（玻璃），每个字符代表 1 单位该类型的垃圾，拾取 1 单位垃圾需要 1 分钟。

另有一个整数数组 `travel`，`travel[i]` 表示从房子 i 到房子 i+1 所需的分钟数。

城市中有三辆垃圾车，分别负责收集一种类型的垃圾。每辆车从房子 0 出发，必须按顺序访问房子（不需要访问所有房子）。同一时刻只能有一辆车在行驶或收集垃圾。

返回收集所有垃圾所需的最少分钟数。

## 解题思路
关键观察：**三辆车独立工作**，且同一时刻只能有一辆车操作。因此总时间 = 三辆车各自花费的时间之和，互不影响。

对每种垃圾类型：
1. **收集时间** = 该类型在所有房子的总出现次数（每个单位 1 分钟）
2. **行驶时间** = 从房子 0 到包含该类型的最远房子之间的路程总和

算法步骤：
- 遍历所有房子，统计每种垃圾的总数量，并记录每种垃圾的最后出现位置
- 对每种类型，收集时间 = 总数量，行驶时间 = 前缀和 `sum(travel[:last_pos])`
- 三类时间相加即为答案

## 复杂度分析
- **时间复杂度：** O(N × K)，N = garbage.length，K 为每个字符串平均长度（≤ 10）
- **空间复杂度：** O(1)

## Python 解法要点
- 用字典 `last_pos` 和 `total_count` 分别记录每种垃圾的最后位置和总数量
- 最后用 `sum(travel[:last_pos[c]])` 计算行驶时间

## Java 解法要点
- 用 `int` 变量记录每种垃圾的统计信息，性能更优
- 先计算前缀行驶时间数组 `prefixTravel`，避免重复求和
- `prefixTravel[i]` 表示从房子 0 到房子 i 的总行驶时间
