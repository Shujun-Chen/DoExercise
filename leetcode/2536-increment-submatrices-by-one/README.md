# 2536. Increment Submatrices by One

**难度：** Medium

## 题目描述

给定一个 `n x n` 的矩阵 `mat`，初始时所有元素都为 `0`。对每个查询 `[row1, col1, row2, col2]`，将子矩阵中所有元素加 `1`，其中子矩阵的左上角为 `(row1, col1)`，右下角为 `(row2, col2)`。返回处理完所有查询后的矩阵。

**示例 1：**
输入：`n = 3, queries = [[1,1,2,2],[0,0,1,1]]`
输出：`[[1,1,0],[1,2,1],[0,1,1]]`

**示例 2：**
输入：`n = 2, queries = [[0,0,1,1]]`
输出：`[[1,1],[1,1]]`

**约束条件：**
- `1 <= n <= 500`
- `1 <= queries.length <= 10^4`
- `0 <= row1 <= row2 < n`
- `0 <= col1 <= col2 < n`

## 解题思路

这是一个典型的**二维差分数组**问题。

**朴素思路：** 对每个查询都遍历它的子矩阵，单次操作 O(面积)，总复杂度 O(n² × q)。当 `n = 500`、`q = 10⁴` 时最坏情况达到 2.5 × 10⁹，必然超时。

**差分数组优化：** 利用"打标记 + 前缀和还原"的两步策略，将总复杂度降到 O(n² + q)：

1. **初始化差分数组：** 创建 `(n+1) x (n+1)` 的二维数组 `diff`，初始全 0。多出的一行一列用于处理 `r2+1` 或 `c2+1` 越界的情况。

2. **对每个查询打四个标记：** 给定查询 `(r1, c1, r2, c2)`，执行
   ```
   diff[r1][c1]     += 1
   diff[r1][c2 + 1] -= 1    # 仅当 c2 + 1 <= n 时
   diff[r2 + 1][c1] -= 1    # 仅当 r2 + 1 <= n 时
   diff[r2 + 1][c2 + 1] += 1 # 仅当 r2 + 1, c2 + 1 <= n 时
   ```
   这相当于将子矩阵的"影响"叠加到差分数组上。

3. **二维前缀和还原：** 对 `diff` 先按行做前缀和（从左到右），再按列做前缀和（从上到下）。这样 `diff` 本身就变成了最终矩阵在差分意义上的还原值。

4. 取前 `n x n` 部分即为答案。

**为什么这样可行？** 二维差分数组中任意点 `(i, j)` 的值，等于以 `(0, 0)` 为原点、`(i, j)` 为右下角的"前缀区域"的累计增量总和。从左上到右下扫两遍前缀和就能让所有标记"扩散"到正确的位置。

## 复杂度分析

- **时间复杂度：** O(n² + q) — 处理 q 个查询是 O(q)，做两次 n² 规模的前缀和扫描
- **空间复杂度：** O(n²) — 差分数组本身

## Python 解法要点

- 使用列表推导式 `[[0]*(n+1) for _ in range(n+1)]` 创建 `(n+1) x (n+1)` 的差分数组。
- 分两次做前缀和：第一次水平方向 `for j in range(1, n+1): diff[i][j] += diff[i][j-1]`；第二次垂直方向 `for i in range(1, n+1): diff[i][j] += diff[i-1][j]`。顺序不影响结果。
- 用列表切片 `[row[:n] for row in diff[:n]]` 提取结果矩阵。

## Java 解法要点

- `int[][] diff = new int[n+1][n+1]` 多分配一行一列，避免打标记时 `r2+1` 或 `c2+1` 数组越界。
- 用 `for (int[] q : queries)` 简化遍历参数。
- 用 `Arrays.deepEquals()` 在测试中比较二维数组，比手写逐元素比较更简洁。
- 注意 `String` 拼接的输出用 `Arrays.deepToString(r1)` 比手写循环更清晰。
