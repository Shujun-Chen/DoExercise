# 2566. Number of Unequal Triplets in Array

**难度：** Easy

## 题目描述

给你一个**下标从 0 开始**的正整数数组 `nums`。找出满足以下条件的三元组 `(i, j, k)` 的数目：

- `0 <= i < j < k < nums.length`
- `nums[i]`、`nums[j]` 和 `nums[k]` 两两互不相同

即：`nums[i] != nums[j]`、`nums[i] != nums[k]`、`nums[j] != nums[k]`

**示例 1：**

```
输入：nums = [4,4,2,4,3]
输出：3
解释：满足条件的三元组为 (0,2,4)、(1,2,4)、(2,3,4)
```

**示例 2：**

```
输入：nums = [1,1,1,1,1]
输出：0
解释：所有元素都相同，没有满足条件的三元组
```

**约束条件：**
- `3 <= nums.length <= 100`
- `1 <= nums[i] <= 1000`

## 解题思路

### 方法：计数组合法（推荐，O(n) 时间）

核心思想是**用总三元组数减去包含重复数字的三元组数**。

**步骤：**

1. **统计频率**：使用哈希表统计每个数字的出现次数。
2. **计算总三元组数**：从 n 个元素中选 3 个的组合数 C(n, 3)。
3. **减去非法三元组**：对每个出现 c 次的值：
   - **恰好两个重复**：从 c 个相同值中选 2 个，再从其余 n-c 个元素中选 1 个。组合数 = C(c, 2) × (n - c)
   - **三个都重复**：从 c 个相同值中选 3 个。组合数 = C(c, 3)
4. **返回结果**：剩余的就是两两互不相同的三元组。

### 为什么这样是有效的？

因为一个三元组要么全部不同（合法），要么包含至少一对相同值（非法）。而包含重复的情况只有两种：恰好两个相同 OR 三个都相同。这些情况互斥，直接减掉即可。

### 替代方案：暴力枚举 O(n³)

由于 `n ≤ 100`，三重循环的时间复杂度为 100³ = 10⁶，完全可行。但计数组合法更优雅、更高效。

## 复杂度分析

- **时间复杂度：** O(n) — 只需一次遍历统计频率，一次遍历计算结果。
- **空间复杂度：** O(n) — 哈希表存储频率，最多 n 个不同值。

## Python 解法要点

- 使用 `collections.Counter` 统计频率
- 使用 `math.comb` 计算组合数（Python 3.8+）
- 注意先检查 `c >= 2` 和 `c >= 3` 再计算

## Java 解法要点

- 使用 `HashMap<Integer, Integer>` 统计频率
- 用 `long` 类型计算中间值，避免溢出（虽然 n ≤ 100 不会溢出，但这是良好的工程习惯）
- 组合数直接用手动公式：C(a, b) = a*(a-1)*.../b!
