# 263. Ugly Number

**难度：** Easy

## 题目描述

丑数（Ugly Number）是一个正整数，其质因数只包含 2、3 和 5。

给定一个整数 `n`，如果 `n` 是丑数则返回 `true`，否则返回 `false`。

## 解题思路

1. 根据定义，丑数的质因数只能是 2、3、5，所以只需不断除以这三个因子
2. 如果最终剩余值为 1，说明该数只包含 2、3、5 的因子，是丑数
3. 如果最终剩余值不为 1（例如 7、11 等），说明包含了其他质因数，不是丑数
4. 特殊情况：0 和负数不是丑数

### 步骤
1. 如果 `n <= 0`，直接返回 `false`
2. 依次用 2、3、5 去除 `n`，能整除就继续除
3. 最后检查 `n` 是否等于 1

## 复杂度分析
- **时间复杂度：** O(log n) — 每次除法至少将 n 减小一半
- **空间复杂度：** O(1) — 只使用了常数级别的额外空间

## Python 解法要点
- 使用 `//=` 整除运算，避免浮点精度问题
- 先处理边界条件 `n <= 0`，再进入循环

## Java 解法要点
- 使用 `int[] factors = {2, 3, 5}` 数组遍历因子，代码更简洁
- 使用 `assert` 进行测试验证
