# 2739. Total Distance Traveled

**难度：** Easy

**标签：** Math, Simulation

## 题目描述

一辆卡车有两个油箱。给定主油箱燃油量 `mainTank`（升）和副油箱燃油量 `additionalTank`（升）。

卡车每升燃油可行驶 10 km。每当主油箱消耗掉 5 升燃油时，如果副油箱至少有 1 升燃油，则会从副油箱向主油箱转移 1 升燃油。

返回卡车能行驶的最大距离。

**注意：** 副油箱的补充不是连续的，每消耗 5 升才突然补充一次。

## 解题思路

1. **模拟法**：逐轮模拟燃油消耗过程
2. 每轮最多消耗 5 升主油箱燃油，同时累计行驶距离
3. 若本轮恰好消耗了 5 升且副油箱有剩余燃油，则从副油箱转移 1 升到主油箱
4. 重复直到主油箱为空

**数学优化思路（可选）：**
- 每消耗 5 升获得 1 升补充，相当于额外多了 `mainTank / 5` 升（但补充的油也能触发新的补充）
- 更精确的公式需要递归计算补充次数

## 复杂度分析

- **时间复杂度：** O(mainTank / 5)，每轮至少消耗 5 升
- **空间复杂度：** O(1)，只使用常数个变量

## Python 解法要点

- 使用 `while` 循环模拟消耗过程
- `min(5, mainTank)` 处理最后一轮不足 5 升的情况
- 每升 10 km，累加距离

## Java 解法要点

- 逻辑与 Python 版本一致
- 使用 `Math.min` 取本轮消耗量
- `assert` 验证测试用例（运行时需加 `-ea` 参数）
