# 2762. Continuous Subarrays

**难度：** Medium

## 题目描述

给定一个 0-indexed 的整数数组 nums。如果一个子数组满足以下条件，则称其为"连续子数组"：

对于子数组中的每一对索引 i1, i2（i1 <= i2），都有 0 <= |nums[i1] - nums[i2]| <= 2。

返回连续子数组的总数。

## 解题思路

**核心观察：** 一个子数组是连续的，当且仅当子数组内的最大值与最小值之差不超过 2。

因此问题转化为：统计所有满足 max - min <= 2 的子数组个数。

**方法：滑动窗口 + 双单调队列**

1. **维护两个单调队列：**
   - `max_deque`：递减队列，队首始终是当前窗口的最大值
   - `min_deque`：递增队列，队首始终是当前窗口的最小值

2. **右指针 right 从左到右遍历：**
   - 将 nums[right] 加入两个队列，维护单调性
   - 检查当前窗口 [left, right] 是否满足 max - min <= 2
   - 如果不满足，移动 left 指针直到满足条件

3. **统计子数组个数：**
   - 当窗口 [left, right] 满足条件时，以 right 结尾的连续子数组有 (right - left + 1) 个
   - 累加到结果中

**为什么是 O(n)？** 每个元素最多被加入队列一次、移除一次，所以总操作次数是 O(n)。

## 复杂度分析

- **时间复杂度：** O(n) — 每个元素最多进出队列各一次
- **空间复杂度：** O(n) — 队列最多存储 n 个元素

## Python 解法要点

- 使用 `collections.deque` 实现双端队列
- 队列中存储下标而非值，便于判断元素是否还在窗口内
- 当队首元素的下标 < left 时，说明已离开窗口，需要弹出

## Java 解法要点

- 使用 `ArrayDeque<Integer>` 实现双端队列
- `peekFirst()` 查看队首，`pollFirst()` 弹出队首
- `addLast()` 在队尾添加，`pollLast()` 弹出队尾
- 注意结果用 `long` 类型，因为子数组个数可能超过 int 范围
