# 2780. Minimum Index of a Valid Split

**难度：** Medium

## 题目描述

给定一个整数数组 `nums`，其中存在一个**支配元素**（出现次数超过数组长度一半的元素）。你可以在下标 `i` 处将数组分割为左右两个子数组 `nums[0..i]` 和 `nums[i+1..n-1]`。如果分割后左右两个子数组拥有**相同的支配元素**，则该分割有效。

请返回**最小的有效分割下标**。如果不存在有效分割，返回 `-1`。

**示例 1：**
```
输入：nums = [1,2,2,2]
输出：2
解释：在下标 2 处分割得到 [1,2,2] 和 [2]。元素 2 在左右子数组中都是支配元素。
```

**示例 2：**
```
输入：nums = [2,1,3,1,1,1,7,1,2,1]
输出：4
解释：在下标 4 处分割得到 [2,1,3,1,1] 和 [1,7,1,2,1]。元素 1 在左右子数组中都是支配元素。
```

**示例 3：**
```
输入：nums = [3,3,3,3,7,2,2]
输出：-1
解释：不存在有效分割。
```

## 解题思路

核心观察：整个数组只有一个支配元素，因此任何有效分割的支配元素**必然就是这个全局支配元素**。
理由：如果某个分割点左右子数组的支配元素相同，那么它一定也是整个数组的支配元素（因为整个数组是该元素的超集）。

利用这一性质，解题分为三步：

1. **找出全局支配元素** — 使用 Boyer-Moore 投票算法，一趟扫描即可找出出现次数最多的候选元素。由于题目保证存在支配元素，该算法能正确找出它。
2. **统计全局出现次数** — 再次扫描数组，统计支配元素的总出现次数。
3. **遍历分割点** — 从左到右扫描，维护左子数组中支配元素的出现次数。对于每个下标 i，检查左右子数组中支配元素是否都超过一半。

## 复杂度分析

- **时间复杂度：** O(n) — 两次线性扫描（Boyer-Moore + 频率统计 + 遍历分割点），实际相当于三次遍历，常数级系数。
- **空间复杂度：** O(1) — 只使用若干变量，没有使用额外的数组或哈希表。

## Python 解法要点

- 使用 `count` 变量和减法实现 Boyer-Moore 投票
- 第二趟扫描遍历 `i` 从 0 到 n-2（保证右子数组非空）
- 条件 `left_freq * 2 > left_len` 等价于支配元素出现次数超过一半

## Java 解法要点

- 使用 `List<Integer>` 和 `nums.get(i)` 访问元素
- 注意 Java 的 `==` 比较 `Integer` 对象时，在 [-128, 127] 范围内安全，但本题数值范围大，使用 `intValue()` 或自动拆箱即可
- `main` 方法中使用 `List.of()` 创建不可变列表
- 使用 `assert` 进行简单测试，需要 JVM 开启断言（`-ea` 参数），或改用条件判断 + 打印
