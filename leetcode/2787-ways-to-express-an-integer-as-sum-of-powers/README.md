# 2787. Ways to Express an Integer as Sum of Powers

**难度：** Medium

## 题目描述
给定两个正整数 `n` 和 `x`，统计有多少组互不相同的正整数，使这些整数的 `x` 次幂之和等于 `n`。答案可能很大，需要对 `10^9 + 7` 取模。

例如，`n = 10, x = 2` 时，只有 `1² + 3² = 10` 这一种表示方法。

## 解题思路
把所有不超过 `n` 的 `x` 次幂依次看作物品，问题就转化为一个目标容量为 `n` 的 0-1 背包计数问题：

1. 定义 `dp[sum]` 表示使用已经处理过的幂值，组成和 `sum` 的方案数。
2. 初始化 `dp[0] = 1`，表示不选任何数时组成 0 有一种方案。
3. 枚举每个幂值 `power = base^x`。
4. 对 `sum` 从 `n` 到 `power` 倒序更新：`dp[sum] += dp[sum - power]`。
5. 倒序更新使每个幂值只会被使用一次，因此满足正整数互不相同的限制。
6. 最终 `dp[n]` 就是答案。

## 复杂度分析
设不超过 `n` 的 `x` 次幂共有 `m = floor(n^(1/x))` 个。

- **时间复杂度：** O(n × n^(1/x))
- **空间复杂度：** O(n)

## Python 解法要点
使用一维列表保存背包状态，并在每次累加后取模。Python 的整数不会溢出，可直接用 `base ** x` 生成幂值。

## Java 解法要点
使用 `long[]` 保存中间计数，避免两个取模结果相加时出现 `int` 溢出。幂值通过逐次相乘计算，超过 `n` 时提前停止，避免无意义计算和整数溢出。
