# 2860. Happy Students

**难度：** Medium

## 题目描述

给定一个长度为 `n` 的整数数组 `nums`，表示班级中每位学生的要求值。老师尝试选出一组学生，使得所有学生都开心。

第 `i` 位学生开心的条件（二选一）：
- **被选中**，且选中的学生总数 **严格大于** `nums[i]`
- **未被选中**，且选中的学生总数 **严格小于** `nums[i]`

返回让所有学生都开心的选组方式数量。

## 解题思路

### 核心观察
对 `nums` 排序后，设选中学生数为 `k`：

1. **选中**的学生需满足：`nums[i] < k`（因为选中人数必须严格大于其要求值）
2. **未选中**的学生需满足：`nums[j] > k`（因为选中人数必须严格小于其要求值）

最优策略是选择 `nums` 值最小的 `k` 个学生——如果连这些学生都不满足条件，更大的值更不可能。

### 算法步骤
1. 将 `nums` 升序排序
2. 枚举 `k` 从 `0` 到 `n`（选中人数）：
   - 若 `k > 0`：检查 `nums[k-1] < k`（前 k 个最小值的选中者都开心）
   - 若 `k < n`：检查 `nums[k] > k`（剩余未选中的都开心）
   - 两个条件都满足 → 答案加 1
3. 返回答案

### 例子
`nums = [1, 1]` 排序后为 `[1, 1]`，`n = 2`：
- `k = 0`：`nums[0] = 1 > 0` ✓ → 1 种
- `k = 1`：`nums[0] = 1 >= 1` ✗ → 跳过
- `k = 2`：`nums[1] = 1 < 2` ✓ → 1 种
- 共 2 种

## 复杂度分析

- **时间复杂度：** O(n log n) — 排序占主导，枚举 O(n)
- **空间复杂度：** O(1) — 原地排序（Java 需 O(n) 拷贝）

## Python 解法要点

- 使用 `sort()` 原地排序
- 用 `range(n + 1)` 枚举所有可能的选中人数
- 注意边界条件：`k=0` 时没有选中者检查，`k=n` 时没有未选中者检查

## Java 解法要点

- `List<Integer>` 转 `int[]` 后用 `Arrays.sort()`
- `k=0` 和 `k=n` 的边界情况需单独处理
- `main` 方法中通过 `Arrays.asList()` 构造测试用例
