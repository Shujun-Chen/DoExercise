# 2998. Minimum Number of Operations to Make X and Y Equal

**难度：** Medium

## 题目描述

给定两个正整数 `x` 和 `y`，每次操作可以执行以下四种操作之一：

1. 如果 `x` 是 11 的倍数，将 `x` 除以 11
2. 如果 `x` 是 5 的倍数，将 `x` 除以 5
3. 将 `x` 减 1
4. 将 `x` 加 1

返回使 `x` 和 `y` 相等所需的**最少**操作次数。

**示例 1：**
```
输入：x = 26, y = 1
输出：3
解释：26 → 25（减1）→ 5（除以5）→ 1（除以5）
```

**示例 2：**
```
输入：x = 54, y = 2
输出：4
解释：54 → 55（加1）→ 5（除以11）→ 1（除以5）→ 2（加1）
```

**示例 3：**
```
输入：x = 25, y = 30
输出：5
解释：25 → 26 → 27 → 28 → 29 → 30（加1五次）
```

**约束条件：**
- `1 <= x, y <= 10^4`

## 解题思路

### 核心观察

1. **当 `y >= x` 时**，划分操作只能让数字变小，所以唯一选择是递增，答案为 `y - x`。

2. **当 `y < x` 时**，有两种策略：
   - **纯递减**：直接减 1 直到等于 `y`，需要 `x - y` 次操作。
   - **利用除法**：先将 `x` 调整到 5 或 11 的倍数（通过递增或递减），然后执行除法，使数值大幅减小，再递归处理。

3. **上界**：由于纯递减只需要 `x - y` 步，任何导致中间值超过 `x + (x - y)` 的操作路径都不可能是最优的。这限制了搜索范围。

### 记忆化搜索（DP）

定义 `dfs(val)` 为从 `val` 到 `y` 的最少操作次数：

- **基本情况**：如果 `val <= y`，返回 `y - val`（只能递增）。
- **递归**：
  - 直接递减：`val - y`
  - 尝试除以 11：先调整到最近的 11 的倍数（向上或向下），执行除法，然后递归
  - 尝试除以 5：同样的策略

由于每次除法操作都会显著减小数值，递归深度有限。使用 `@lru_cache` 避免重复计算。

### 关键技巧

为了处理"先递增到倍数再除法"的场景（例如 `x=10, y=1`：10→11→1），需要同时考虑**向上**和**向下**调整到最接近的倍数。这比 BFS 更高效，因为它直接利用了数学性质来剪枝。

## 复杂度分析

- **时间复杂度：** O(U)，其中 U = x + (x - y) 是搜索上界。每个状态最多访问一次。
- **空间复杂度：** O(U)，用于记忆化递归的缓存。

## Python 解法要点

- 使用 `functools.lru_cache` 实现记忆化
- 利用 `x % 5` 和 `x % 11` 计算到最近倍数的距离
- 向上调整的倍数计算：`(base - r) % base` 即 `val + (base - val % base)`

## Java 解法要点

- 使用 `HashMap<Integer, Integer>` 作为记忆化缓存
- 用 `Integer.MAX_VALUE / 2` 表示不可达路径（避免加法溢出）
- 成员变量存储 `y` 和 `upper` 以便递归函数访问
