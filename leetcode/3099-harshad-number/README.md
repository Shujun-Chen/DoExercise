# 3099. Harshad Number

**难度：** Easy

## 题目描述

如果一个整数能够被它的各位数字之和整除，那么这个整数称为哈沙德数（Harshad Number）。

给定整数 `x`：
- 如果 `x` 是哈沙德数，返回 `x` 的各位数字之和；
- 否则返回 `-1`。

约束：`1 <= x <= 100`。

## 解题思路

1. 保存原始数字 `x`，用于最后的整除判断。
2. 不断取 `x % 10` 得到当前最低位，将其加入数字和。
3. 通过整数除法 `x //= 10`（Java 中为 `x /= 10`）去掉最低位，直到所有位都处理完。
4. 如果原始数字能够被数字和整除，返回数字和；否则返回 `-1`。

由于题目保证 `x >= 1`，各位数字之和一定大于 `0`，不会发生除零问题。

## 复杂度分析

- **时间复杂度：** O(log x)，遍历整数的每一位数字。
- **空间复杂度：** O(1)，只使用常数个额外变量。

## Python 解法要点

使用 `% 10` 和 `// 10` 逐位拆分整数，并在计算完成后用保存的原始值执行取模判断。

## Java 解法要点

使用整型变量累计数字和，通过三元表达式直接返回数字和或 `-1`；`main` 方法使用断言覆盖示例和边界测试。
