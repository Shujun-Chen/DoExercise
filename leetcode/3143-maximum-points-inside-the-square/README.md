# 3143. Maximum Points Inside the Square

**难度：** Medium

## 题目描述

给定一个 2D 数组 `points` 和字符串 `s`，其中 `points[i]` 表示第 i 个点的坐标，`s[i]` 表示第 i 个点的标签（tag）。

一个"有效正方形"以原点 `(0,0)` 为中心、边平行于坐标轴，并且**不**包含两个 tag 相同的点。返回能放进一个有效正方形中的点的最大数量。

注意：
- 点位于正方形边界上也算在内部。
- 正方形边长可以为 0（即只包含原点处的点）。

## 解题思路

由于正方形中心在原点、边平行于坐标轴，边长为 `L` 的正方形覆盖所有满足 `max(|x|, |y|) <= L/2` 的点（"切比雪夫距离"）。

1. **关键转化**：对每个点定义 `r_i = max(|x_i|, |y_i|)`，则点被某个边长为 `L` 的正方形覆盖等价于 `L >= 2 * r_i`，即 `r_i` 越小的点越靠近原点，越容易被覆盖。
2. **整体性观察**：把所有点按 `r` 升序排序后，**`r` 值相同的若干点必须"全选"或"全不选"**——因为我们只能调整 `L/2` 这道"边界"，落在同一 `r` 上的一组点要么都在内、要么都在外，无法只取部分。
3. **贪心遍历**：按 `r` 从小到大逐组处理，每组同时检查两个条件：
   - 组内无重复 tag；
   - 与已纳入的 tag 集合无冲突。
   都满足则整组纳入并累加点数；否则停止，停在的位置就是答案。
4. **为什么停下来的就是答案**：在停止之前，所有纳入的点都满足 tag 互异；之后的组要么组内重复、要么与已纳入的 tag 冲突——无论怎样扩大 `L` 都无法再纳入新的点（至少不能整组纳入，而整组是必须的）。

## 复杂度分析

- **时间复杂度：** O(n log n)（排序主导，遍历 O(n)）
- **空间复杂度：** O(n)（存放 items / idx 数组及 set）

## Python 解法要点

- 用生成器表达式 `sorted((max(abs(x), abs(y)), tag) for ...)` 把 `(r, tag)` 对一次排好。
- 外层 `while i < n` 配合内层 `while items[j][0] == r_i` 把相同 `r` 切成一组。
- 用 `len(set(group_tags)) != len(group_tags)` 快速判组内重复；用 `any(t in seen for t in group_tags)` 判组间冲突。

## Java 解法要点

- Java 不能直接对 `int[][]` 排序，因此用 `Integer[] idx` 保存下标并对下标排序。
- 抽 `chebyshev(int[] p)` 辅助方法，避免重复书写 `Math.max(Math.abs(...), Math.abs(...))`。
- `groupSet.size() != group.size()` 一行判组内重复。
