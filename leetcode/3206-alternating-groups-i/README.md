# 3206. Alternating Groups I

**难度：** Easy

## 题目描述

给定一个表示圆形排列的红蓝瓦片数组 `colors`，其中 `colors[i] == 0` 表示红色，`colors[i] == 1` 表示蓝色。如果 3 个连续瓦片中，中间瓦片的颜色与左右两侧都不同，则称为一个**交替组**。返回交替组的数量。

注意：因为是圆形排列，第一个和最后一个瓦片相邻。

## 解题思路

1. 由于数组是环形的，使用取模运算 `(i ± 1) % n` 来处理边界
2. 遍历每个位置 `i`，检查 `colors[i]` 是否与左右邻居颜色都不同
3. 如果满足条件，计数加一
4. 返回总计数

## 复杂度分析
- **时间复杂度：** O(n)，遍历每个位置一次
- **空间复杂度：** O(1)，只用常数额外空间

## Python 解法要点
- 使用 `% n` 处理环形索引
- `List[int]` 类型标注

## Java 解法要点
- 使用 `(i - 1 + n) % n` 避免负数取模问题
- 数组长度至少为 3，无需额外空数组检查
