# 3234. Count the Number of Substrings With Dominant Ones

**难度：** Medium

## 题目描述

给定一个二进制字符串 `s`，统计其中含有"主导 1"的子串数量。

如果一个子串中 **1 的数量大于等于 0 的数量的平方**，则称该子串含有"主导 1"。

**示例 1：**

```
输入: s = "00011"
输出: 5
解释：
包含主导 1 的子串：
- (3,3): "1" — 1 个 1, 0 个 0, 1 >= 0² ✓
- (4,4): "1" — 1 个 1, 0 个 0 ✓
- (2,3): "01" — 1 个 1, 1 个 0, 1 >= 1²=1 ✓
- (3,4): "11" — 2 个 1, 0 个 0 ✓
- (2,4): "011" — 2 个 1, 1 个 0, 2 >= 1²=1 ✓
```

**示例 2：**

```
输入: s = "101101"
输出: 16
解释：21 个子串中共有 16 个包含主导 1。
```

**约束条件：**
- `1 <= s.length <= 4 * 10⁴`
- `s` 只包含字符 `'0'` 和 `'1'`

## 解题思路

### 核心观察

在长度为 n 的字符串中，对于包含 z 个 0 的子串，需要至少 z² 个 1 才能满足条件。因此子串的总长度至少为 z² + z，所以 z² + z ≤ n，即 **z ≤ sqrt(n)**。这意味着有效子串中最多只有约 sqrt(n) 个 0。

### 算法步骤

**第一步：统计全 1 子串**

所有只包含 1 的子串（0 个 0）都满足条件。统计每个连续的"1 段"，长度为 L 的段贡献 L×(L+1)/2 个子串。

**第二步：统计包含至少一个 0 的有效子串**

1. 记录所有 0 的位置到数组 `zeros` 中
2. 枚举每个 0 作为子串的"第一个 0"
3. 对于每个第一个 0，枚举后续最多 sqrt(n) 个 0，形成一组 (firstZero, lastZero)，其中包含 z 个 0
4. 左边界 l 从 (上一个 0 + 1) 到 firstZero
5. 右边界 end 从 lastZero 到 (下一个 0 - 1)
6. 条件：end - l + 1 ≥ z² + z，即 end ≥ l + z² + z - 1
7. 通过数学推导，可以直接计算满足条件的 (l, end) 对数，无需逐一遍历

### 推导细节

对于每组 (firstZero, lastZero)：
- z = 0 的个数
- K = z² + z - 1
- 左边界范围：leftStart ≤ l ≤ firstZero
- 右边界范围：lastZero ≤ end < nextZero
- 需要 end ≥ l + K

当 l + K ≥ lastZero 时，最小结束位置由 l + K 决定；否则由 lastZero 决定。

通过分界点 threshold_l = lastZero - K，可以在 O(1) 时间内用等差数列求和公式计算出所有有效 (l, end) 对的数量。

## 复杂度分析

- **时间复杂度：** O(n × sqrt(n))
  - 外层枚举 n 个 0 的位置，内层枚举 sqrt(n) 个 0
  - 每个内层循环 O(1) 数学计算
  - 总体 O(n × sqrt(n))，对于 n ≤ 4×10⁴ 足够高效

- **空间复杂度：** O(n) — 用于存储 0 的位置数组

## Python 解法要点

- 用 `long` 类型（Python 自动支持大整数）避免中间计算溢出
- 将全 1 子串和含 0 子串分开计数，避免重复
- 利用等差数列求和公式 `Σl = (start + end) × cnt / 2` 优化计算

## Java 解法要点

- 使用 `long` 类型进行中间计算，最后转回 `int`
- 注意 `Math.min`/`Math.max` 的边界条件处理
- Java 的 `Math.sqrt` 返回 `double`，需要转为 `int`
