# 324. Wiggle Sort II

**难度：** Medium

## 题目描述

给定一个整数数组 `nums`，将其重新排列为如下摆动顺序：

`nums[0] < nums[1] > nums[2] < nums[3] ...`

你可以假设输入数组总是存在有效答案。

**示例 1：**

```
输入：nums = [1,5,1,1,6,4]
输出：[1,6,1,5,1,4]
解释：[1,4,1,5,1,6] 也是可以接受的。
```

**示例 2：**

```
输入：nums = [1,3,2,2,3,1]
输出：[2,3,1,3,1,2]
```

**约束条件：**
- `1 <= nums.length <= 5 * 10^4`
- `0 <= nums[i] <= 5000`
- 输入保证存在有效答案

**进阶：** 能否用 O(n) 时间和/或 O(1) 额外空间原地完成？

## 解题思路

### 核心思想

摆动排序的关键是：**较小的数放在偶数位，较大的数放在奇数位**。

### 步骤

1. **排序**：先将原数组排序，得到有序序列
2. **分割**：将排序后的数组分成左右两半
   - 左半部分（较小元素）：下标 `[0, mid-1]`
   - 右半部分（较大元素）：下标 `[mid, n-1]`
   - 其中 `mid = (n+1) / 2`
3. **逆序填充**：
   - 偶数位（0, 2, 4, ...）：从**右向左**取左半部分的元素
   - 奇数位（1, 3, 5, ...）：从**右向左**取右半部分的元素

### 为什么逆序？

如果正序填充，当数组中有大量重复元素时，可能出现相邻元素相等的情况。
逆序可以避免这种情况，因为有重复值的元素会被分散到两端。

例如 `[1, 1, 1, 4, 5, 6]`：
- 左半 `[1, 1, 1]`（逆序取：1, 1, 1 放到 0, 2, 4）
- 右半 `[4, 5, 6]`（逆序取：6, 5, 4 放到 1, 3, 5）
- 结果：`[1, 6, 1, 5, 1, 4]` ✓

### 进阶解法

可以使用**中位数 + 虚拟索引 + 三路划分**实现 O(n) 时间、O(1) 空间的原地算法：
1. 用快速选择（nth_element）找出中位数
2. 通过虚拟索引映射，在虚拟空间上进行三路划分（Dutch National Flag）
3. 大于中位数的放左边（实际分配到奇数位），小于中位数的放右边（实际分配到偶数位）

## 复杂度分析

- **时间复杂度：** O(n log n) — 排序主导。进阶解法可达 O(n)
- **空间复杂度：** O(n) — 使用了额外数组。进阶解法可达 O(1)

## Python 解法要点

- 使用 `sorted()` 排序后，通过分割指针分别从左、右半逆序填充
- 进阶解法使用三路划分 + 虚拟索引映射 `(2*i+1) % (n|1)`
- 注意 `List[int]` 类型注解需要从 typing 导入

## Java 解法要点

- 使用 `Arrays.sort()` 排序，`clone()` 复制数组
- 注意 Java 中 `(n + 1) / 2` 是整数除法，自动向下取整
- `main` 方法中进行完整的测试验证
