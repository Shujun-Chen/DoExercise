# 3480. Maximize Subarrays After Removing One Conflicting Pair

**难度：** Hard

## 题目描述

给定整数 `n` 表示数组 `nums = [1, 2, ..., n]`，以及二维数组 `conflictingPairs`，其中 `conflictingPairs[i] = [a, b]` 表示 `a` 和 `b` 构成一个冲突对。

需要从 `conflictingPairs` 中恰好删除一个元素，然后统计 `nums` 中不包含任意剩余冲突对两个元素（即同时包含 `a` 和 `b`）的非空子数组数量。

返回删除恰好一个冲突对后能得到的最大子数组数。

## 解题思路

### 核心观察

1. **标准化冲突对**：将每对 `(x, y)` 标准化为 `(a, b)`，其中 `a = min(x, y)，b = max(x, y)`。
2. **子数组有效条件**：子数组 `[L, R]` 有效当且仅当不存在冲突对 `(a, b)` 使得 `L ≤ a < b ≤ R`。
3. **瓶颈概念**：对于固定起始位置 `L`，有效子数组的右端点必须小于所有活动冲突对（即 `a ≥ L` 的冲突对）中的最小 `b` 值。

### 算法设计

**步骤 1 — 计算原始有效子数组数**
- 从右向左扫描位置 `i = n` 到 `1`。
- 维护一个活动冲突对集合（所有 `a ≥ i` 的冲突对）。
- 维护最小值 `minB` 和次小值 `secondMinB`。
- 对于位置 `i`，有效子数组数为 `minB - i`（若 `minB = INF` 则为 `n + 1 - i`）。

**步骤 2 — 计算每个冲突对的删除收益**
- 当冲突对 `(a, b)` 是某个位置 `i` 的瓶颈（即 `b = minB`）时，删除它会将该位置的 `minB` 提升为 `secondMinB`。
- 收益增量 = `secondMinB - minB`（若 `secondMinB = INF` 则为 `n + 1 - minB`）。
- 将每个位置的收益累加到对应冲突对。

**步骤 3 — 取最大值**
- 原始总数 + 所有冲突对中最大的删除收益 = 答案。

### 正确性证明

- 活动集合的单调性：当 `i` 递减时，更多冲突对进入活动集合，`minB` 单调不增。
- 累加正确性：冲突对 `(a, b)` 在其 `a` 值首次被处理时进入活动集合，此后对所有更小的 `i` 持续生效，直到出现更小的 `b` 值将其取代。
- 贡献的线性叠加：每个起始位置 `i` 的收益可以独立计算并累加到其瓶颈冲突对。

## 复杂度分析

- **时间复杂度：** O(n + m)，其中 m = len(conflictingPairs)。只需一次从右向左扫描。
- **空间复杂度：** O(n + m)，用于存储按 a 分组的冲突对和收益数组。

## Python 解法要点

- 使用 `defaultdict(list)` 按 `a` 值分组冲突对。
- 从右向左迭代 `i = n, n-1, ..., 1`，实时更新 `minB` 和 `secondMinB`。
- 注意使用 `INF = n + 5` 避免边界判断。

## Java 解法要点

- 使用 `ArrayList<int[]>[]` 邻接表按 `a` 分组。
- 结果用 `long` 类型避免 `n` 较大时溢出（n ≤ 10^5，子数组数可达 5 × 10^9）。
- 通过 `Math.min` / `Math.max` 标准化冲突对的顺序。
