# 3486. Longest Special Path II

**难度：** Hard

## 题目描述

给定一棵以节点 0 为根的无向树，包含 n 个节点（编号 0 到 n-1）。`edges` 数组表示边信息 `[u, v, length]`，`nums` 数组表示节点值。

定义"**特殊路径**"为从祖先节点到后代节点的向下路径，其中所有节点值互不相同，但允许**恰好一个值出现两次**。

返回数组 `result`，其中 `result[0]` 是最长特殊路径的**长度**（边权之和），`result[1]` 是所有最长特殊路径中**节点数的最小值**。

## 解题思路

1. **构建邻接表**：将 edges 转换为邻接表表示树结构
2. **DFS 遍历 + 滑动窗口**：
   - 维护从根到当前节点的路径（`path_vals`）和累计距离（`path_dist`）
   - 使用 `count` 字典统计当前窗口内各值出现次数
   - 定义 `excess = sum(max(0, count[v] - 1))`，表示路径中重复值的总量
3. **窗口收缩**：当 `excess > 1` 时，从窗口左端逐个移除节点，直到 `excess <= 1`
4. **前缀和计算路径长度**：`curr_len = path_dist[idx] - path_dist[start]`
5. **回溯恢复**：记录收缩过程中移除的节点，DFS 回溯时恢复状态

## 复杂度分析

- **时间复杂度：** O(n)，每个节点最多被加入和移除路径各一次
- **空间复杂度：** O(n)，用于存储路径、计数和邻接表

## Python 解法要点

- 使用 `defaultdict(int)` 维护值计数
- 使用 `removed` 列表记录收缩过程中的状态变化，回溯时逆序恢复
- 通过前缀和差值 O(1) 计算路径长度

## Java 解法要点

- 使用 `ArrayList` 维护路径和距离，`HashMap` 维护计数
- 使用实例变量简化 DFS 状态传递，避免参数过多
- 回溯逻辑与 Python 版本对称，保证状态一致性
