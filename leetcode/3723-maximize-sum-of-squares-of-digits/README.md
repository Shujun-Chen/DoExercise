# 3723. Maximize Sum of Squares of Digits

**难度：** Medium

## 题目描述

给定两个正整数 `num` 和 `sum`。一个正整数 n 是"好的"，当且仅当：
- n 恰好有 `num` 位数字
- n 的各位数字之和恰好等于 `sum`

n 的得分定义为各位数字的平方和。返回得分最大的好整数（字符串形式）。如果存在多个，返回数值最大的那个；如果不存在，返回空字符串。

## 解题思路

**核心观察：** 对于固定的数字和，平方和是凸函数——将和集中在尽可能大的数字上能最大化平方和。

### 贪心策略

1. **可行性判断：** 每位数字最大为 9，因此最大数字和为 `num * 9`。若 `sum > num * 9`，则无解，返回空字符串。

2. **最大化平方和：** 由于 `9² = 81` 带来的平方收益最大，应尽可能多地使用数字 9：
   - `count9 = sum / 9`（9 的个数）
   - `remainder = sum % 9`（余数，0~8）

3. **最大化数值：** 平方和相同的不同排列中，将较大的数字放在高位能得到更大的整数。因此：
   - 将所有 9 放在最前面
   - 紧随余数（若余数 > 0）
   - 其余低位补 0

4. **构造结果字符串：** `"9" * count9 + str(remainder) + "0" * (zeros)`

### 示例推导

以 `num=2, sum=17` 为例：
- `count9 = 17 / 9 = 1`，`remainder = 17 % 9 = 8`
- 构造：1 个 9 + 余数 8 = `"98"`
- 得分：`9² + 8² = 81 + 64 = 145`，为最大值

## 复杂度分析

- **时间复杂度：** O(num) — 需要构造长度为 num 的结果字符串
- **空间复杂度：** O(num) — 存储结果字符串

## Python 解法要点

- 使用 `"9" * count9` 批量生成重复字符，效率高
- 用列表收集各部分字符串，最后 `join` 拼接，避免多次字符串相加
- 边界条件：`digitSum > num * 9` 时直接返回空串

## Java 解法要点

- 使用 `StringBuilder` 高效拼接字符串
- `"9".repeat(count9)` 批量生成重复字符（Java 11+）
- 注意 `num * 9` 可能溢出 int，使用 `num * 9L` 避免
