# 3731. Find Missing Elements

**难度：** Easy

## 题目描述

给定一个由 **唯一** 整数组成的数组 `nums`。

最初，`nums` 包含某个范围内的 **所有整数**。然而，某些整数可能从数组中 **缺失** 了。

原始范围的 **最小** 和 **最大** 整数仍然存在于 `nums` 中。

返回按升序排列的所有缺失整数列表。如果没有缺失，返回空列表。

**示例 1：**

```
输入：nums = [1,4,2,5]
输出：[3]
解释：最小值为 1，最大值为 5，完整的范围应为 [1,2,3,4,5]，其中只有 3 缺失。
```

**示例 2：**

```
输入：nums = [7,8,6,9]
输出：[]
解释：最小值为 6，最大值为 9，完整范围为 [6,7,8,9]，所有整数都存在。
```

**示例 3：**

```
输入：nums = [5,1]
输出：[2,3,4]
解释：最小值为 1，最大值为 5，完整范围为 [1,2,3,4,5]，缺失 2, 3, 4。
```

**约束条件：**

- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 10^5`
- `nums` 中的所有整数都是唯一的。
- 原始范围的最小值和最大值一定存在于 `nums` 中。

## 解题思路

这道题的关键在于理解题目的核心信息：

1. **最小值与最大值确定原始范围**：题目保证最小值和最大值都在数组中，因此原始范围就是 `[min(nums), max(nums)]`。
2. **找出缺失值**：遍历整个范围，检查每个整数是否在数组中。

**步骤：**

1. 遍历数组，求出 `minVal` 和 `maxVal`。
2. 将数组元素存入哈希集合，实现 O(1) 的查找。
3. 从 `minVal` 遍历到 `maxVal`，不在集合中的值即为缺失值，加入结果列表。

> 由于遍历顺序从小到大，结果列表天然有序，无需额外排序操作。

## 复杂度分析

- **时间复杂度：** O(n) — 求最小值/最大值需要 O(n)，构建哈希集合需要 O(n)，遍历范围最坏情况下也只需 O(n)（范围长度 ≤ n）。
- **空间复杂度：** O(n) — 哈希集合存储数组元素。

## Python 解法要点

- 使用 `set(nums)` 构建哈希集合，实现 O(1) 的成员查找
- 使用 `range(min_val, max_val + 1)` 遍历完整的数值范围
- 列表推导式可以简写为 `[i for i in range(min_val, max_val + 1) if i not in num_set]`

## Java 解法要点

- 使用 `HashSet<Integer>` 存储数组元素
- 用 `Integer.MAX_VALUE` 和 `Integer.MIN_VALUE` 初始化 min/max 变量
- 使用 `ArrayList<Integer>` 存储结果，添加时自动维护插入顺序
