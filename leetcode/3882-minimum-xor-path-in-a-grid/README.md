# 3882. Minimum XOR Path in a Grid

**难度：** Medium

## 题目描述
给定一个 `m x n` 的二维整数网格 `grid`。从左上角 `(0, 0)` 出发，每一步只能向右或向下移动，直到到达右下角 `(m-1, n-1)`。

一条路径的代价定义为路径上所有经过单元格数值的按位异或（XOR）结果。返回所有合法路径中的最小代价。

约束：`1 <= m * n <= 1000`，`0 <= grid[i][j] <= 1023`。

## 解题思路
由于 `grid[i][j] <= 1023`，任意路径的异或结果始终落在 `[0, 1023]` 区间内（异或不会产生更高位），因此每个位置可达到的异或值只有 1024 种可能。

据此设计动态规划：对每个单元格维护一个「可达异或值集合」，表示从起点走到该格时所有可能的异或结果。

1. 起点集合为 `{grid[0][0]}`。
2. 对于单元格 `(i, j)`，它可以由上方 `(i-1, j)` 或左方 `(i, j-1)` 转移而来。
   把上方与左方的可达集合合并，再逐一与 `grid[i][j]` 做异或，得到当前格的可达集合。
3. 终点 `(m-1, n-1)` 的可达集合中的最小值即为答案。

空间优化：按列滚动。只保留「当前行每一列」的可达状态。
- 处理 `(i, j)` 时，`col[j]`（更新前）保存的是上一行同列 `(i-1, j)` 的状态，即「上方来源」；
- 同一行左侧的 `(i, j-1)` 已经更新到 `col[j-1]`，即「左方来源」；
- 合并两者再异或 `grid[i][j]`，写回 `col[j]`。

Python 用 `set` 数组表示每列的可达值；Java 用 `boolean[1024]` 数组表示每列的可达标记。

## 复杂度分析
- **时间复杂度：** O(m * n * 1024)。每个单元格需遍历 1024 个可能的异或值。因 `m * n <= 1000`，总量可接受。
- **空间复杂度：** O(n * 1024)。仅保留一行（n 列）的滚动状态。

## Python 解法要点
- 用长度为 `n` 的列表 `col`，每个元素是一个 `set`，保存该列当前可达的异或值。
- 遍历顺序为逐行、逐列。处理 `(i, j)` 前，`col[j]` 仍是上方来源，`col[j-1]` 已是左方来源。
- 合并来源集合后，与 `grid[i][j]` 异或写回 `col[j]`。
- 最终返回 `min(col[n-1])`。

## Java 解法要点
- 用 `boolean[n][1024]` 表示每列各异或值是否可达，实现按列滚动。
- 处理 `(i, j)` 时先把上方状态 `col[j]`（旧值）与左方状态 `col[j-1]`（本行已更新）合并为来源标记。
- 对每个可达来源值 `x`，将 `x ^ grid[i][j]` 标记为当前格可达，写入临时数组后覆盖 `col[j]`，避免读写冲突。
- 最终在 `col[n-1]` 中取最小的被标记下标作为答案。
