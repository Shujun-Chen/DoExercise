# 4283. Multi Source Flood Fill

**难度：** Medium

## 题目描述

给定两个整数 `n` 和 `m`，表示一个网格的行数和列数。

再给定一个二维数组 `sources`，其中 `sources[i] = [r_i, c_i, color_i]` 表示格子 `(r_i, c_i)` 初始被染为 `color_i` 颜色。其他格子初始未染色，用 0 表示。

在每个时间步，每个已染色的格子同时向四个方向（上、下、左、右）的**未染色**格子扩散自己的颜色。

如果**多个**颜色在同一时间步到达同一个未染色格子，该格子取**颜色值最大**的那个。

重复此过程直到没有格子可以染色为止。返回最终的网格状态。

## 解题思路

### 核心思想：多源 BFS（广度优先搜索）

由于所有颜色同时扩散，这是一个典型的多源 BFS 问题——就像从多个火源同时引燃草地一样。

**关键观察：**
1. 扩散是**同步**的（同一时间步所有颜色同时向外扩展一层）
2. 同时到达时取**最大颜色值**
3. 已经染色的格子不会再次改变颜色（除非同一时间步被更大颜色覆盖）

**BFS 实现步骤：**
1. 初始化 `n x m` 的网格，所有格子设为 0
2. 将每个 source 的位置作为 BFS 起点入队，记录其颜色和时间步 0
3. 使用队列逐层 BFS 遍历：
   - 出队一个格子 `(r, c)`
   - 检查四个相邻格子
   - 如果相邻格子从未被访问：设置其颜色为当前颜色，时间步 +1，入队
   - 如果相邻格子已被访问但在**同一时间步**：取当前颜色和已有颜色的最大值（更新颜色但不入队）
4. BFS 结束后返回最终网格

**为什么 BFS 能模拟同步扩散？** BFS 天然按"层"遍历，同一层的格子对应同一时间步。多源 BFS 同时从所有起点出发，保证了"所有格子同时向外扩散"的语义。

## 复杂度分析

- **时间复杂度：** O(n × m) — 每个格子最多被处理一次，队列操作和邻居检查均为常数时间
- **空间复杂度：** O(n × m) — 网格数组、dist 距离数组和 BFS 队列各需 O(n×m) 空间

## Python 解法要点

- 使用 `collections.deque` 实现高效队列操作
- `dist` 数组用于记录每个格子被首次染色的时间步，防止重复处理
- 遇到 `dist[nr][nc] == cur_dist + 1` 即"同一时间步"的情况时，仅更新颜色值
- 使用方向数组 `dirs = [(-1,0), (1,0), (0,-1), (0,1)]` 简化四个方向的遍历

## Java 解法要点

- 使用 `Queue<int[]>` 和 `LinkedList` 实现 BFS 队列
- `Arrays.fill(dist[i], -1)` 初始化 dist 数组
- 用 `Arrays.deepEquals` 验证二维数组的相等性
- 方法签名需与原题一致：`public int[][] colorGrid(int n, int m, int[][] sources)`
