# 686. Repeated String Match

**难度：** Medium

## 题目描述

给定两个字符串 `a` 和 `b`，要求将字符串 `a` 重复若干次（可以为 0 次），使得 `b` 变成其子串。返回最少需要重复的次数；若不可能则返回 `-1`。

**注意：** `"abc"` 重复 0 次是 `""`，重复 1 次是 `"abc"`，重复 2 次是 `"abcabc"`。

**示例 1：**
```
输入：a = "abcd", b = "cdabcdab"
输出：3
解释：重复 a 三次得到 "abcdabcdabcd"，其中 "cdabcdab" 是其子串。
```

**示例 2：**
```
输入：a = "a", b = "aa"
输出：2
```

**约束：**
- `1 <= a.length, b.length <= 10^4`
- `a` 和 `b` 都由小写英文字母组成

## 解题思路

1. **可行性预判**：先把 `a` 的所有字符放入集合。若 `b` 中存在 `a` 没有的字符，则无论重复多少次 `a`，都不可能产生 `b`，直接返回 `-1`。
2. **枚举重复次数**：设 `m = len(a)`、`n = len(b)`，那么 `b` 必然出现在长度 `>= n` 的 `a^k` 中。考虑到 `b` 起点可能跨过 `a` 的边界（参考示例 1），最多枚举 `n / m + 2` 次即可覆盖所有情形。
3. **检查子串**：每次把 `a` 拼接到当前字符串后面，用 `find` / `indexOf` 检查 `b` 是否出现；首次出现即返回当前重复次数。

## 复杂度分析

- **时间复杂度：** `O(n + m)`，其中 `n = len(b)`、`m = len(a)`。字符串拼接与 `find` 在每次循环里线性增长，总开销受 `n/m + 2` 个周期累加。
- **空间复杂度：** `O(n + m)`，来自拼接产生的临时字符串。

## Python 解法要点

- 用 `set(b) - set(a)` 一行判断可行性。
- 在循环中累积 `repeated += a`，避免每次 `k * a` 重新拼接浪费内存。
- `b in repeated` 等价于 `repeated.find(b) != -1`，更 Pythonic。

## Java 解法要点

- 用 `HashSet<Character>` 预判字符可行性。
- 使用 `StringBuilder` 累积字符串，比反复 `+` 拼接性能更稳定。
- `StringBuilder.indexOf(String)` 返回首次出现位置，`-1` 表示未找到。
