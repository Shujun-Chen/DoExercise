# 789. Escape The Ghosts

**难度：** Medium

## 题目描述

在一个无限的二维网格上玩简化版 PAC-MAN 游戏。你从原点 `[0, 0]` 出发，目标是到达 `target = [x_target, y_target]`。地图上有若干个鬼，起始位置由 `ghosts` 数组给出，`ghosts[i] = [x_i, y_i]`。

每一轮，你和所有鬼都可以独立选择向四个基本方向（北、东、南、西）移动 1 格，或者原地不动。所有动作同时发生。

**逃脱条件：** 你能在任意鬼到达你之前到达目标点。如果你和某个鬼同时到达同一个格子（包括目标点），不算逃脱。

请判断：无论鬼如何移动，你是否都能逃脱？

## 解题思路

这道题的关键洞察是**曼哈顿距离**的性质。

### 分析

1. **最优策略：** 在曼哈顿距离度量下，无论是 PAC-MAN 还是鬼，最优策略都是沿最短路径（沿坐标轴方向）直线移动，不会有任何迂回策略能更快到达目的地。

2. **PAC-MAN 的距离：** 从 `[0, 0]` 到 `target` 的曼哈顿距离为 `|target[0]| + |target[1]|`。

3. **鬼的距离：** 每个鬼从 `ghosts[i]` 到 `target` 的曼哈顿距离为 `|target[0] - ghosts[i][0]| + |target[1] - ghosts[i][1]|`。

4. **判断条件：** 如果存在任何一个鬼，其到 target 的曼哈顿距离 **≤** PAC-MAN 到 target 的曼哈顿距离，则该鬼可以在 PAC-MAN 到达之前（或同时）到达 target，PAC-MAN 无法逃脱。

5. **结论：** 只有当 PAC-MAN 到 target 的曼哈顿距离**严格小于**所有鬼到 target 的曼哈顿距离时，PAC-MAN 才能逃脱。

## 复杂度分析

- **时间复杂度：** O(n)，其中 n 为鬼的数量，需要遍历所有鬼计算曼哈顿距离
- **空间复杂度：** O(1)，只使用了常数额外空间

## Python 解法要点

- 使用 `abs()` 计算曼哈顿距离
- 遍历所有鬼，一旦发现某个鬼的距离 ≤ PAC-MAN 的距离，立即返回 `False`
- 通过所有检查后返回 `True`

## Java 解法要点

- 使用 `Math.abs()` 计算曼哈顿距离
- 遍历逻辑与 Python 一致
- Java 的 `assert` 需要加 `-ea` 参数编译运行
