# 836. Rectangle Overlap

**难度：** Easy

## 题目描述

两个轴对齐矩形分别用列表 `[x1, y1, x2, y2]` 表示，其中 `(x1, y1)` 是左下角坐标，`(x2, y2)` 是右上角坐标。矩形的边平行于 X 轴和 Y 轴。

如果两个矩形的交集面积为正，则称它们重叠。仅边或角接触的情况**不**算重叠。

给定两个矩形 `rec1` 和 `rec2`，判断它们是否重叠。

## 解题思路

两个矩形在轴对齐的情况下，判断重叠的经典方法是分别检查它们在 x 轴和 y 轴上的投影是否有交集。

1. **x 轴投影**：矩形 1 的 x 区间为 `[x1, x2]`，矩形 2 的 x 区间为 `[x3, x4]`。投影重叠的条件是：
   - `max(x1, x3) < min(x2, x4)` — 即两个区间有重合部分（不包含端点，因为边接触不算重叠）。
2. **y 轴投影**：同理，y 区间重叠的条件是：
   - `max(y1, y3) < min(y2, y4)`。
3. **最终结论**：当两个方向上的投影都有重叠（交集为正）时，矩形重叠。

逆向思考更容易理解：一个矩形如果在另一个的左侧（`x2 <= x3`）、右侧（`x1 >= x4`）、上方（`y1 >= y4`）或下方（`y2 <= y3`），则肯定不重叠。排除这四种情况后，必然重叠。

## 复杂度分析

- **时间复杂度：** O(1) — 仅进行常数次比较操作
- **空间复杂度：** O(1) — 只使用固定数量的变量

## Python 解法要点

- 利用 Python 的 `max` 和 `min` 函数简洁地比较区间重叠
- `typing.List` 用于类型注解
- 条件使用严格小于 `<` 而非 `<=`，以排除边接触的情况

## Java 解法要点

- 使用 `Math.max` 和 `Math.min` 方法进行区间比较
- `main` 方法中用 `assert` 进行测试，需在运行时启用断言（`-ea` 参数）
- 注意 `int[]` 数组的下标访问
